What to check, and the choices for you

  • Stock in purchase units. "2.3 trays" instead of "68 pcs", because ordering is done in trays. The base unit still shows on the item page.
  • Choice: suggested quantity. The mockup suggests enough to bring stock back up to 2× the minimum, rounded up to whole packs (Eggs: 180 − 68 = 112 pcs → 4 trays). Other options: back up to just the minimum, or no suggestion.
  • On order shows how much is already ordered but not yet received, so the same thing isn't ordered twice.
  • Price defaults to the last price paid and only changes on the review step or when receiving. Ordering never asks for a price.
  • Review & send opens one summary page (items, total, delivery date, note), then sends. Send to supplier stays as it is today (WhatsApp / copy text).
  • Receiving starts with every line arrived in full. Only problem lines need a tap. Over-delivery uses the same Edit, the note rule stays as today, and the database rules stay the same.
  • Internal transfers (to HQ) use the same New PO cards. "On hand" shows the branch's own stock.
  • Desktop: the same screens become a wider centred column. Items, Suppliers, Recipes and the Stock on Hand table stay as they are.
