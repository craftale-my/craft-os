# POS Receipt Template, Call Numbers and Cash Drawer (W4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Takeaway customers are called by a short number (TA001–TA999 per outlet and business day), the receipt carries the shop's logo, a footer QR, a font size and no free add-on noise, and the cash drawer opens by itself for cash and on demand, with every no-sale open logged.

**Architecture:** One SQL migration (two tasks): a call-number counter and two `before insert` triggers (bills get `call_no`, kitchen tickets get `callNo`), four receipt columns saved by `save_receipt_settings` and carried by both receipt payloads, a `drawer` print job queued before a receipt by the payment / part / refund / cash-move functions, `pos_open_drawer` with its log, and a no-sale count in the Z report and the Cash drawer report. On the client, printing moves from lines to a small document (`PrintDoc`: text, big text, image, QR, pulse) that the ESC/POS encoder turns into bytes for the print agent, while Epson / Star keep the text view; the settings page gets the logo upload, QR, font size, the free add-ons switch and "Opens the cash drawer"; the till shows call numbers and an Open drawer button.

**Tech Stack:** Supabase Postgres (plpgsql / sql functions, triggers), React 19 + TypeScript + Vite, Tailwind, Vitest + Testing Library (jsdom per file), Node print agent (`node --env-file … agent.ts`, type stripping).

**Spec:** `docs/superpowers/specs/2026-11-22-pos-receipt-numbers-design.md` (owner approved 2026-11-22; binding).

## Spec conflicts

Places where the code makes a spec point impossible or wrong as written. Each is resolved as stated; nothing else departs from the spec.

1. **§6 "redefines … the functions that create bills".** Five paths insert into `bills` (`pos_insert_order` in migration-2026-10-24-pos-slots-photos-fn.sql, `open_table` in migration-2026-10-24-pos-bill-actions-fn.sql, `checkout_items` and `move_items` in migration-2026-11-16-pos-split-bill.sql; QR orders go through `pos_insert_order`), and the ticket payload is built inside the 250-line `pos_insert_order` and in `pos_queue_void_tickets`. **Resolution:** a `before insert` trigger `bills_call_no` sets `call_no` on every new bill (split part → its source's; takeaway → a new number; dine-in → none) and a `before insert` trigger `print_jobs_call_no` adds `callNo` to a ticket's payload from its order's bill. Same behaviour on every path (and on paths added later, e.g. Grab), no copy of the five functions, nothing for a re-run of an older file to undo.
2. **§6 "the payment-method save".** There is no SQL save function: `savePaymentMethod` (src/features/pos/checkout/checkoutApi.ts) upserts `payment_methods` directly under the RLS policy `payment_methods_manage` (migration-2026-10-29-pos-outlets.sql). **Resolution:** the migration adds the column; the client reads and sends `opens_drawer`.
3. **§5 "A print job of kind `drawer`".** `print_jobs.kind` has `check (kind in ('ticket', 'receipt'))` (migration-2026-10-23-pos-ordering.sql); the Z report and the refund slip already ride on `kind = 'receipt'` with their own `payload.kind`. **Resolution:** column `kind = 'receipt'`, `payload.kind = 'drawer'` (`{ kind: 'drawer', route, reason }` exactly as the spec).
4. **§5 "queued before that payment's receipt".** Both jobs are inserted in one transaction, so they share `created_at` (`now()`), `print_jobs.id` is random, and the agent handles Realtime events concurrently (each `handle` races to `claim_print_job`). "Before" cannot be guaranteed as things are. **Resolution:** `print_jobs.seq bigint generated by default as identity`; the agent and the iPad read pending jobs ordered by `created_at, seq` and handle one job at a time per route, in arrival order (Realtime delivers a transaction's inserts in insert order).
5. **§2 `pos_next_call_no(p_branch_id, p_channel)`** uses "now", so the verify could not place a bill at 05:30 and 06:30. **Resolution:** a third argument `p_at timestamptz default now()` (the trigger passes the bill's `opened_at`); called with two arguments it is the spec's function.
6. **§5 "no receipt route = no kick"** for Open drawer: logging an open that cannot kick would count a no-sale open that never happened. **Resolution:** `pos_open_drawer` refuses `No receipt printer is set — choose one in POS settings` (the words `reprint_receipt` already uses) and logs nothing. Payments, refunds and cash moves simply skip the kick, as the spec says.
7. **§3 "checks the shape and the size and refuses `The logo must be at most 384 × 240 dots.` otherwise"** — one message cannot tell a cashier both "too big" and "broken file". **Resolution:** too wide or too high → the spec's message; any other bad shape (width not a multiple of 8, wrong byte count, not base64) → `The logo could not be read. Upload it again.`

## Spec notes (readings taken where the spec is silent)

1. **Reason defaults** live in the client (`defaultTemplate('open_drawer')`: the three spec reasons, a reason required, Other allowed). The server with no `reason_templates` row accepts any non-empty reason, which is the same rule. Settings → Reasons pre-fills the three for an outlet with no saved row; nothing is inserted by the migration.
2. **Who sees Open drawer:** everyone signed in on the till (no capability), as the spec says "no supervisor PIN".
3. **A stale drawer kick** (never tried, older than 2 minutes) is left pending by the agent — a late kick would open the drawer with nobody at the till. It shows as Waiting on the iPad like an old ticket. Tickets keep `MAX_AGE_MIN`.
4. **The Z report line** is the last line of the CASH DRAWER section, printed as `Drawer opened without a sale: 2` (also when 0); reports frozen before W4 have no key and print no line.
5. **The call number on paper:** first block of a receipt, part receipt and ticket (above the logo); the text-only view (Epson, Star, tests) centres it as plain text.
6. **Free add-ons** = `modifiers_snapshot[].priceDeltaSen` is the number 0. A snapshot without `priceDeltaSen` (older than the catalogs migration) is kept.
7. **`opens_drawer` on existing methods:** set true for every `cash` method only when the column is first added (a re-run does not turn back on a method the owner turned off).
8. **Transactions search** matches the call number as typed (`TA12`, `ta012`, `12`, with or without spaces) on top of the bill number and the table / `TA012 · Takeaway` text; the screen lists today's bills as now.
9. **Payment-method form default:** a new row starts as `other` with the switch off; choosing `cash` on a new (unsaved) row turns it on; a saved row keeps its switch when its kind changes.

```sql
-- ── C1. Call numbers (spec §2) ──────────────────────────────────────────────
-- One counter per outlet, channel and business day; next_no is the number the next bill gets.
create table if not exists pos_call_counters (
  branch_id     uuid not null references branches(id),
  channel       text not null,
  business_day  date not null,
  next_no       integer not null default 1 check (next_no between 1 and 999),
  primary key (branch_id, channel, business_day)
);
alter table pos_call_counters enable row level security;
revoke all on pos_call_counters from public, anon, authenticated;

alter table bills add column if not exists call_no text;                                         -- C1

-- The next call number of an outlet's channel on the business day of p_at: TA001 … TA999, then TA001.
-- Atomic: the upsert takes the row lock, so two bills at once get two numbers. Internal.
create or replace function pos_next_call_no(p_branch_id uuid, p_channel text, p_at timestamptz default now())
returns text
language plpgsql security definer set search_path = public, pg_temp as $$
declare
  v_prefix text := case p_channel when 'takeaway' then 'TA' end;
  v_next   integer;
begin
  if v_prefix is null then raise exception 'Unknown call number channel %', p_channel; end if;
  insert into pos_call_counters(branch_id, channel, business_day, next_no)
  values (p_branch_id, p_channel, pos_business_day(p_at), 2)
  on conflict (branch_id, channel, business_day) do update set next_no = pos_call_counters.next_no % 999 + 1
  returning next_no into v_next;
  -- v_next is the number after the one given: 2 → 1, 1 (after 999) → 999
  return v_prefix || lpad(((v_next + 997) % 999 + 1)::text, 3, '0');
end $$;
revoke all on function pos_next_call_no(uuid, text, timestamptz) from public, anon, authenticated;

-- Every new bill: a part split off by item keeps its source's number, a takeaway bill gets the next one,
-- a dine-in bill none (the table is its number). A number given by the caller is kept. Internal.
create or replace function bills_call_no() returns trigger
language plpgsql security definer set search_path = public, pg_temp as $$
begin
  if new.call_no is not null then return new; end if;
  if new.split_from is not null then
    new.call_no := (select b.call_no from bills b where b.id = new.split_from);
  elsif new.order_type = 'takeaway' then
    new.call_no := pos_next_call_no(new.branch_id, 'takeaway', new.opened_at);
  end if;
  return new;
end $$;
revoke all on function bills_call_no() from public, anon, authenticated;
drop trigger if exists bills_call_no on bills;
create trigger bills_call_no before insert on bills for each row execute function bills_call_no();
```

```sql
alter table reason_templates drop constraint if exists reason_templates_action_check;

-- A drawer kick on the outlet's receipt printer: prints nothing, pulses the drawer. print_jobs.kind stays
-- 'receipt' (its check allows ticket / receipt), the payload is DrawerPayload (src/features/pos/print/printJob.ts).
-- false = no receipt route, no kick. Queued in the caller's transaction before its receipt: print_jobs.seq
-- keeps that order. Internal.
create or replace function pos_queue_drawer(p_branch_id uuid, p_reason text) returns boolean
language plpgsql security definer set search_path = public, pg_temp as $$
declare
  v_route text;
begin
  select s.receipt_route into v_route from branch_pos_settings s where s.branch_id = p_branch_id;
  if v_route is null then return false; end if;
  insert into print_jobs(branch_id, route, kind, payload)
  values (p_branch_id, v_route, 'receipt', jsonb_build_object('kind', 'drawer', 'route', v_route, 'reason', p_reason));
  return true;
end $$;
revoke all on function pos_queue_drawer(uuid, text) from public, anon, authenticated;

-- pos_pay_and_close: the text of migration-2026-11-16-pos-split-bill.sql (S3) with the lines marked C3

-- part paid by item (checkout_items) kick the drawer before the receipt when a method opens it. Internal.
create or replace function pos_pay_and_close(p_bill_id uuid, p_branch uuid, p_shift uuid, p_payments jsonb,
                                             p_totals jsonb, p_checkout_id uuid) returns jsonb
language plpgsql security definer set search_path = public, pg_temp as $$
declare
  v_queued boolean;
begin

     set status = 'paid', closed_at = now(), closed_by = pos_actor(), closed_device_id = pos_current_device(), checkout_id = p_checkout_id,
         shift_id = p_shift,
         totals = p_totals,
         subtotal_sen       = (p_totals->>'subtotalSen')::integer,
         service_charge_sen = (p_totals->>'serviceChargeSen')::integer,
         sst_sen            = (p_totals->>'sstSen')::integer,
         takeaway_fee_sen   = (p_totals->>'takeawayFeeSen')::integer,
         rounding_sen       = (p_totals->>'roundingSen')::integer,
         total_sen          = (p_totals->>'totalSen')::integer
   where id = p_bill_id;
  if exists (select 1 from payments p join payment_methods m on m.id = p.method_id                       -- C3
              where p.bill_id = p_bill_id and p.part_id is null and m.opens_drawer) then                -- C3
    perform pos_queue_drawer(p_branch, 'Payment');                                                        -- C3

  return pos_checkout_result(p_bill_id);
```

```sql
-- ── C4. Open drawer (spec §5) ───────────────────────────────────────────────
-- A no-sale open: the caller's outlet (pos_my_branch) needs an open shift; the reason follows the outlet's
-- open_drawer template (pos_check_reason); no supervisor PIN. Logged in pos_drawer_opens, then kicked on
-- the receipt printer. With no receipt printer nothing is logged: an open that cannot happen is not counted.
-- p_id is the client's: a resend of the same id answers again without a second kick.
create or replace function pos_open_drawer(p_id uuid, p_reason text) returns jsonb
language plpgsql security definer set search_path = public, pg_temp as $$
declare
  v_branch   uuid := pos_my_branch();
  v_existing pos_drawer_opens;
  v_shift    uuid;
  v_reason   text;
  v_route    text;
begin
  if p_id is null then raise exception 'Drawer open id is missing'; end if;
  select * into v_existing from pos_drawer_opens where id = p_id;
  if found then
    if v_existing.branch_id <> v_branch then raise exception 'This drawer open id belongs to another outlet'; end if;
    return jsonb_build_object('ok', true, 'id', v_existing.id);
  end if;
  select id into v_shift from pos_shifts where branch_id = v_branch and status = 'open' for share;
  if not found then raise exception 'Open a shift first.'; end if;
  v_reason := pos_check_reason(v_branch, 'open_drawer', p_reason);
  select s.receipt_route into v_route from branch_pos_settings s where s.branch_id = v_branch;
  if v_route is null then raise exception 'No receipt printer is set — choose one in POS settings'; end if;
  insert into pos_drawer_opens(id, branch_id, shift_id, opened_by, reason)
  values (p_id, v_branch, v_shift, pos_actor(), v_reason)
  on conflict (id) do nothing;
  if not found then                                                       -- the same id won meanwhile
    return pos_open_drawer(p_id, p_reason);
  end if;
  perform pos_queue_drawer(v_branch, coalesce(v_reason, 'Open drawer'));
  return jsonb_build_object('ok', true, 'id', p_id);
end $$;
```

```ts
// Explicit .ts extensions: the Node print agent loads this file directly (no bundler).

/** The receipt's font (W4 spec §3): small = the printer's Font B, large = double height. */
export type FontSize = 'small' | 'normal' | 'large'

/** One block of a printed document (W4 spec §4). `big`: double width and height, centred (a call number).
 *  An image is the logo raster (ReceiptLogo, print/logo.ts); a QR holds its text; a pulse kicks the drawer. */
export type DocBlock =
  | { type: 'text'; text: string; big?: boolean }
  | { type: 'image'; width: number; height: number; data: string }
  | { type: 'qr'; data: string }
  | { type: 'pulse' }

/** What a print job prints. `paper` false: nothing comes out (a drawer kick) — no feed, no cut. */
export interface PrintDoc {
  fontSize: FontSize
  paper: boolean
  blocks: DocBlock[]
}

/** Characters per line: Font B fits a third more (42 → 56); normal and large keep `cols`. */
export function lineWidth(fontSize: FontSize, cols: number): number {
  return fontSize === 'small' ? Math.round((cols * 4) / 3) : cols
}

export function textBlocks(lines: string[]): DocBlock[] {
  return lines.map((text) => ({ type: 'text', text }))
}

/** The text view of a document (tests, Epson ePOS, Star WebPRNT): big text centred as plain text at
 *  `cols`; images, QR codes and pulses left out. */
export function docText(doc: PrintDoc, cols: number): string[] {
  return doc.blocks.flatMap((b) => {
    if (b.type !== 'text') return []
    return b.big ? [' '.repeat(Math.max(0, Math.floor((cols - b.text.length) / 2))) + b.text] : [b.text]
  })
}

/** The document kicks the cash drawer. */
export function docPulses(doc: PrintDoc): boolean {
  return doc.blocks.some((b) => b.type === 'pulse')
}
```

```ts
export function toBase64(bytes: Uint8Array): string {
  let text = ''
  for (let i = 0; i < bytes.length; i += 0x8000) {
    text += String.fromCharCode.apply(null, Array.from(bytes.subarray(i, i + 0x8000)))
  }

  return out
```

```ts
// Explicit .ts extensions: the Node print agent loads this file directly (no bundler).
import { textBlocks, type DocBlock, type PrintDoc } from './doc.ts'
import { fromBase64 } from './logo.ts'

const ESC = 0x1b
const GS = 0x1d
const LF = 0x0a
const QUESTION = 0x3f

/** Only printable ASCII goes through — anything else becomes "?". Chinese needs a printer-specific code
 *  page (GB18030 on Chinese models); whether the shop's printers support it is a spike question. */
function pushText(out: number[], text: string): void {
  for (const ch of text) {
    const code = ch.codePointAt(0) ?? QUESTION
    out.push(code >= 0x20 && code < 0x7f ? code : QUESTION)
  }
}

function pushAll(out: number[], bytes: ArrayLike<number>): void {
  for (let i = 0; i < bytes.length; i++) out.push(bytes[i])
}

/** GS v 0, mode 0: width in bytes and height in dots (little endian), then the raster rows. */
function pushRaster(out: number[], width: number, height: number, data: string): void {
  const row = Math.ceil(width / 8)
  out.push(GS, 0x76, 0x30, 0x00, row & 0xff, row >> 8, height & 0xff, height >> 8)
  pushAll(out, fromBase64(data))
}

/** GS ( k: QR model 2, module size 6, error correction M; the data stored as UTF-8, then printed. */
function pushQr(out: number[], data: string): void {
  const d = new TextEncoder().encode(data)
  const n = d.length + 3
  out.push(GS, 0x28, 0x6b, 0x04, 0x00, 0x31, 0x41, 0x32, 0x00)   // model 2
  out.push(GS, 0x28, 0x6b, 0x03, 0x00, 0x31, 0x43, 0x06)         // module size 6
  out.push(GS, 0x28, 0x6b, 0x03, 0x00, 0x31, 0x45, 0x31)         // error correction M
  out.push(GS, 0x28, 0x6b, n & 0xff, n >> 8, 0x31, 0x50, 0x30)   // store the data
  pushAll(out, d)
  out.push(GS, 0x28, 0x6b, 0x03, 0x00, 0x31, 0x51, 0x30)         // print it
}

/** One block. `small`: the document is in Font B; `size`: the body's GS ! value (0x01 for large). */
function pushBlock(out: number[], b: DocBlock, small: boolean, size: number): void {
  switch (b.type) {
    case 'text':
      if (!b.big) {
        pushText(out, b.text)
        out.push(LF)
        return
      }
      out.push(ESC, 0x61, 0x01)                 // ESC a 1: centre
      if (small) out.push(ESC, 0x4d, 0x00)      // the big line in Font A
      out.push(GS, 0x21, 0x11)                  // GS ! 0x11: double width and height
      pushText(out, b.text)
      out.push(LF)
      out.push(GS, 0x21, size)                  // back to the body's size
      if (small) out.push(ESC, 0x4d, 0x01)
      out.push(ESC, 0x61, 0x00)                 // ESC a 0: left
      return
    case 'image':
      out.push(ESC, 0x61, 0x01)
      pushRaster(out, b.width, b.height, b.data)
      out.push(ESC, 0x61, 0x00)
      return
    case 'qr':
      out.push(ESC, 0x61, 0x01)
      pushQr(out, b.data)
      out.push(ESC, 0x61, 0x00)
      return
    case 'pulse':
      out.push(ESC, 0x70, 0x00, 25, 250)        // ESC p 0 25 250: drawer pin 2, 50 ms on, 500 ms off
      return
  }
}

/** Raw bytes of a document for a generic ESC/POS printer on TCP 9100 (the print agent, W4 spec §4):
 *  ESC @, the font (small: ESC M 1, Font B; large: GS ! 0x01, double height), the blocks, then — when
 *  the document has paper — feed and cut. */
export function encodeEscPosDoc(doc: PrintDoc, opts: { feed?: number; cut?: boolean } = {}): Uint8Array {
  const out: number[] = [ESC, 0x40]
  const small = doc.fontSize === 'small'
  const size = doc.fontSize === 'large' ? 0x01 : 0x00
  if (small) out.push(ESC, 0x4d, 0x01)
  if (size) out.push(GS, 0x21, size)
  for (const b of doc.blocks) pushBlock(out, b, small, size)
  if (doc.paper) {
    out.push(ESC, 0x64, opts.feed ?? 4)
    if (opts.cut ?? true) out.push(GS, 0x56, 0x42, 0x00)
  }
  return Uint8Array.from(out)
}

/** Plain lines, normal font, fed and cut (the bytes the agent sent before W4). */
export function encodeEscPos(lines: string[], opts: { feed?: number; cut?: boolean } = {}): Uint8Array {
  return encodeEscPosDoc({ fontSize: 'normal', paper: true, blocks: textBlocks(lines) }, opts)
}
```

```ts
/** A drawer kick (W4 spec §5): prints nothing; the receipt printer pulses its cash drawer. pos_queue_drawer
 *  builds exactly this (print_jobs.kind stays 'receipt'). Queued before the receipt of the same payment. */
export interface DrawerPayload {
  kind: 'drawer'
  route: string
  reason: string | null // Payment, Part payment, Refund, Pay in, Pay out, or the Open drawer reason
}

/** Everything a print_jobs.payload can hold. Both print hosts (the Node agent and the iPad page) render
 *  through renderJobDoc / renderJobLines, so a new kind is added here once. */
export type JobPayload = TicketPayload | ReceiptPayload | PartReceiptPayload | RefundSlipPayload | ZReportPayload | DrawerPayload

const plain = (lines: string[]): PrintDoc => ({ fontSize: 'normal', paper: true, blocks: textBlocks(lines) })
const callNoBlock = (callNo: string | null | undefined): DocBlock[] => (callNo ? [{ type: 'text', text: callNo, big: true }] : [])

/** A receipt or part receipt: the call number big, the logo, the lines at the font's width, the footer QR.
 *  A payload queued before W4 has none of them: normal font, its lines only. */
function receiptDoc<P extends ReceiptPayload | PartReceiptPayload>(p: P, cols: number, render: (p: P, cols: number) => string[]): PrintDoc {
  const fontSize = p.fontSize ?? 'normal'
  const logo = p.header.logo
  return {
    fontSize,
    paper: true,
    blocks: [
      ...callNoBlock(p.callNo),
      ...(logo ? [{ type: 'image' as const, width: logo.width, height: logo.height, data: logo.data }] : []),
      ...textBlocks(render(p, lineWidth(fontSize, cols))),
      ...(p.footerQr ? [{ type: 'qr' as const, data: p.footerQr }] : []),
    ],
  }
}

/** The document a job prints at `cols` characters a line (the print agent encodes it with encodeEscPosDoc). */
export function renderJobDoc(payload: JobPayload, cols: number): PrintDoc {
  switch (payload.kind) {
    case 'ticket':
      return { fontSize: 'normal', paper: true, blocks: [...callNoBlock(payload.callNo), ...textBlocks(renderTicketLines(payload, cols))] }
    case 'receipt':
      return receiptDoc(payload, cols, renderReceiptLines)
    case 'part':
      return receiptDoc(payload, cols, renderPartReceiptLines)
    case 'refund':
      return plain(renderRefundSlipLines(payload, cols))
    case 'zreport':
      return plain(renderZReportLines(payload, cols))
    case 'drawer':
      return { fontSize: 'normal', paper: false, blocks: [{ type: 'pulse' }] }
    default:
      throw new Error(`Unknown print job kind: ${String((payload as { kind?: unknown }).kind)}`)
  }
}

/** The text view (tests, Epson ePOS, Star WebPRNT): normal font at `cols`, the call number centred as plain
 *  text, no logo, QR or pulse. An old payload gives exactly its renderer's lines. */
export function renderJobLines(payload: JobPayload, cols: number): string[] {
  const normal: JobPayload = payload.kind === 'receipt' || payload.kind === 'part' ? { ...payload, fontSize: 'normal' } : payload
  return docText(renderJobDoc(normal, cols), cols)
}

/** One line for the printer-problems list: what this job is. */
export function jobLabel(payload: JobPayload): string {
  if (payload.kind === 'receipt') return `Receipt ${payload.billNo}${payload.tableLabel ? ` · ${payload.tableLabel}` : ' · takeaway'}`
  if (payload.kind === 'part') return `Part receipt ${payload.billNo} · ${partLabel(payload.partNo, payload.ways)}`
  if (payload.kind === 'refund') return `Refund slip ${payload.billNo}`
  if (payload.kind === 'zreport') return `Z report ${formatMyt(payload.report.closedAt)}${payload.reprint ? ' · REPRINT' : ''}`
  if (payload.kind === 'drawer') return `Cash drawer · ${payload.reason ?? 'Open'}`
  return `${payload.orderNo}${payload.tableLabel ? ` · ${payload.tableLabel}` : ' · takeaway'}${payload.void ? ' · VOID' : ''}`
}
```

```ts
/** A drawer kick never tried for this long is left pending: a late kick would open the drawer with nobody
 *  at the till (W4). */
export const DRAWER_MAX_AGE_MIN = 2

/** The age in minutes of a job too old to print by itself, or null to print it. An old job that was never
 *  tried stays pending (the iPad shows it as "Waiting") so staff decide, not a backlog dump; a requeued one
 *  (attempts >= 1) is a Reprint someone asked for. Tickets wait up to maxAgeMin, a drawer kick 2 minutes. */
export function staleMinutes(
  job: { created_at?: string; attempts?: number; payload?: { kind?: string } },
  nowMs: number,
  maxAgeMin: number,
): number | null {
  if (!job.created_at || (job.attempts ?? 0) > 0) return null
  const ageMin = (nowMs - Date.parse(job.created_at)) / 60_000
  const limit = job.payload?.kind === 'drawer' ? Math.min(DRAWER_MAX_AGE_MIN, maxAgeMin) : maxAgeMin
  return ageMin > limit ? ageMin : null
}
```

```ts
/** The receipt logo, made in the browser when the owner uploads an image (W4 spec §3): scale to fit
 *  384 × 240 dots, grayscale, Floyd–Steinberg dither, pack — rows top to bottom, width / 8 bytes a row,
 *  most significant bit = leftmost dot, 1 = black. Pure: the canvas work is in logoFile.ts. */
import { LOGO_MAX_HEIGHT, LOGO_MAX_WIDTH, toBase64, type ReceiptLogo } from '../print/logo'

/** The printed size: never enlarged, the shape kept, the width down to a multiple of 8 (at least 8). */
export function fitLogoSize(width: number, height: number): { width: number; height: number } {
  const scale = Math.min(1, LOGO_MAX_WIDTH / width, LOGO_MAX_HEIGHT / height)
  const w = Math.max(8, Math.floor((width * scale) / 8) * 8)
  const h = Math.min(LOGO_MAX_HEIGHT, Math.max(1, Math.round((height * w) / width)))
  return { width: w, height: h }
}

/** RGBA → 0 (black) … 255 (white) per dot; transparency shows white paper. */
export function grayscale(rgba: ArrayLike<number>, width: number, height: number): Float32Array {
  const out = new Float32Array(width * height)
  for (let i = 0; i < out.length; i++) {
    const lum = 0.299 * rgba[i * 4] + 0.587 * rgba[i * 4 + 1] + 0.114 * rgba[i * 4 + 2]
    const a = rgba[i * 4 + 3] / 255
    out[i] = lum * a + 255 * (1 - a)
  }
  return out
}

/** Floyd–Steinberg: each dot black (1) below 128, its error spread 7/16 right, 3/16 down-left, 5/16 down,
 *  1/16 down-right. */
export function ditherFloydSteinberg(gray: Float32Array, width: number, height: number): Uint8Array {
  const work = Float32Array.from(gray)
  const bits = new Uint8Array(width * height)
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      const i = y * width + x
      const old = work[i]
      const black = old < 128
      bits[i] = black ? 1 : 0
      const err = old - (black ? 0 : 255)
      if (x + 1 < width) work[i + 1] += (err * 7) / 16
      if (y + 1 < height) {
        if (x > 0) work[i + width - 1] += (err * 3) / 16
        work[i + width] += (err * 5) / 16
        if (x + 1 < width) work[i + width + 1] += err / 16
      }
    }
  }
  return bits
}

export function packBits(bits: Uint8Array, width: number, height: number): Uint8Array {
  const row = Math.ceil(width / 8)
  const out = new Uint8Array(row * height)
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      if (bits[y * width + x]) out[y * row + (x >> 3)] |= 0x80 >> (x & 7)
    }
  }
  return out
}

export function unpackBits(bytes: Uint8Array, width: number, height: number): Uint8Array {
  const row = Math.ceil(width / 8)
  const bits = new Uint8Array(width * height)
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      bits[y * width + x] = (bytes[y * row + (x >> 3)] >> (7 - (x & 7))) & 1
    }
  }
  return bits
}

/** RGBA pixels already at the printed size (fitLogoSize) → the logo as save_receipt_settings takes it. */
export function makeLogo(rgba: ArrayLike<number>, width: number, height: number): ReceiptLogo {
  const bits = ditherFloydSteinberg(grayscale(rgba, width, height), width, height)
  return { width, height, data: toBase64(packBits(bits, width, height)) }
}
```

```ts
/** Browser only (canvas): read an uploaded image into the receipt logo, and draw a logo as it will print.
 *  Never imported by the print agent. */
import { fromBase64, type ReceiptLogo } from '../print/logo'
import { fitLogoSize, makeLogo, unpackBits } from './logoImage'

export async function readLogoFile(file: File): Promise<ReceiptLogo> {
  if (!file.type.startsWith('image/')) throw new Error('Choose an image file (PNG or JPG).')
  let bitmap: ImageBitmap
  try {
    bitmap = await createImageBitmap(file)
  } catch {
    throw new Error('This image could not be read. Try a PNG or JPG.')
  }
  const { width, height } = fitLogoSize(bitmap.width, bitmap.height)
  const canvas = document.createElement('canvas')
  canvas.width = width
  canvas.height = height
  const ctx = canvas.getContext('2d')
  if (!ctx) {
    bitmap.close()
    throw new Error('This browser cannot read images.')
  }
  ctx.fillStyle = '#ffffff'
  ctx.fillRect(0, 0, width, height)
  ctx.drawImage(bitmap, 0, 0, width, height)
  bitmap.close()
  return makeLogo(ctx.getImageData(0, 0, width, height).data, width, height)
}

/** The dithered logo, black dots on white, at its printed size. */
export function drawLogo(canvas: HTMLCanvasElement, logo: ReceiptLogo): void {
  const ctx = canvas.getContext('2d')
  if (!ctx) return
  const bits = unpackBits(fromBase64(logo.data), logo.width, logo.height)
  const img = ctx.createImageData(logo.width, logo.height)
  for (let i = 0; i < bits.length; i++) {
    const v = bits[i] ? 0 : 255
    img.data[i * 4] = v
    img.data[i * 4 + 1] = v
    img.data[i * 4 + 2] = v
    img.data[i * 4 + 3] = 255
  }
  ctx.putImageData(img, 0, 0)
}
```

```tsx
/** POS Settings → Receipt → Logo (W4 spec §3): upload an image, see it as it will print (black dots on
 *  white, at most 384 × 240), remove it. Saved with the other receipt settings. */
export default function ReceiptLogoField({ logo, onChange }: {
  logo: ReceiptLogo | null
  onChange: (logo: ReceiptLogo | null) => void
}) {
  const canvas = useRef<HTMLCanvasElement>(null)
  const [error, setError] = useState<string | null>(null)
  const [busy, setBusy] = useState(false)

    const file = input.files?.[0]
    if (!file) return
    setError(null)
    setBusy(true)

      <div>Logo</div>
```

```ts
/** Takeaway call numbers on screen (W4 spec §2): TA001–TA999 per outlet and business day (bills.call_no). */

/** "TA012 · Takeaway"; "Takeaway" for a bill without a number (before W4). */
export function takeawayLabel(callNo: string | null | undefined): string {
  return callNo ? `${callNo} · Takeaway` : 'Takeaway'
}

/** The Transactions search: "TA12", "ta012", "12" and " TA 012 " all find TA012 — any case, spaces ignored,
 *  leading zeros optional, the prefix optional. */
export function callNoMatches(callNo: string | null | undefined, search: string): boolean {
  if (!callNo) return false
  const q = search.toLowerCase().replace(/\s+/g, '')
  if (!q) return false
  const c = callNo.toLowerCase()
  if (c.includes(q)) return true
  const asked = /^([a-z]*)0*(\d{1,3})$/.exec(q)
  const own = /^([a-z]+)(\d+)$/.exec(c)
  return !!asked && !!own && (asked[1] === '' || asked[1] === own[1]) && Number(asked[2]) === Number(own[2])
}
```

Create `src/features/pos/shift/OpenDrawerDialog.tsx`:

```tsx
import { useEffect, useRef, useState } from 'react'
import { fetchReasonTemplate } from '../checkout/checkoutApi'
import { defaultTemplate, reasonProblem, type ReasonTemplate } from '../checkout/reasons'
import { openDrawer } from './shiftApi'

const msg = (e: unknown) => (e instanceof Error ? e.message : String(e))

/** Open drawer (W4 spec §5, POS grid menu): the cashier picks a reason — the outlet's open_drawer template,
 *  else Give change / Check the cash / Swap a note, Other allowed — and the receipt printer kicks the drawer.
 *  No supervisor PIN; every open is logged and counted on the Z report. One id per dialog: a retry after a
 *  lost reply never kicks twice. */
export default function OpenDrawerDialog({ branchId, onClose }: { branchId: string; onClose: () => void }) {
  const [template, setTemplate] = useState<ReasonTemplate>(defaultTemplate('open_drawer'))
  const [choice, setChoice] = useState('')            // a listed reason, or '' when typing Other
  const [other, setOther] = useState('')
  const [error, setError] = useState<string | null>(null)
  const [busy, setBusy] = useState(false)
  const [done, setDone] = useState(false)
  const id = useRef(crypto.randomUUID())
  const running = useRef(false)                      // a second tap in the same render must not send twice

  useEffect(() => {
    fetchReasonTemplate(branchId, 'open_drawer').then((t) => { if (t) setTemplate(t) }, (e) => setError(msg(e)))
  }, [branchId])

  const reason = choice || other
  const open = async () => {
    const problem = reasonProblem(template, reason)
    if (problem) { setError(problem); return }
    if (running.current) return
    running.current = true
    setBusy(true)
    setError(null)
    try {
      await openDrawer(id.current, reason.trim())
      setDone(true)
    } catch (e) {
      setError(msg(e))
    } finally {
      running.current = false
      setBusy(false)
    }
  }

  return (
    <div className="fixed inset-0 z-40 flex items-center justify-center bg-black/40" onClick={busy ? undefined : onClose}>
      <div role="dialog" aria-label="Open drawer" className="w-full max-w-md space-y-3 rounded-2xl bg-card p-5" onClick={(e) => e.stopPropagation()}>
        <div>
          <h2 className="text-lg font-semibold">Open drawer</h2>
          <p className="text-sm text-brown-muted">Opens the cash drawer without a sale. Every open is logged with its reason.</p>
        </div>
        {done ? (
          <>
            <p role="status" className="rounded bg-green-50 p-3 text-sm text-green-800">Drawer opened.</p>
            <button type="button" onClick={onClose} className="min-h-12 w-full rounded-xl bg-brown-btn text-white">Done</button>
          </>
        ) : (
          <>
            <div>
              <div className="text-xs font-semibold uppercase text-brown-muted">Reason{template.compulsory ? '' : ' (optional)'}</div>
              <div className="mt-1 flex flex-wrap gap-2">
                {template.reasons.map((r) => (
                  <button key={r} type="button" onClick={() => { setChoice(r); setOther(''); setError(null) }}
                    className={`min-h-11 rounded-lg border px-3 text-sm ${choice === r ? 'border-brown-btn bg-brown-btn text-white' : 'border-border'}`}>{r}</button>
                ))}
              </div>
              {template.allowOther && (
                <input className="mt-2 min-h-11 w-full rounded border border-border p-2 text-sm" placeholder={template.reasons.length ? 'Other reason' : 'Reason'}
                  aria-label="Reason" value={other} onChange={(e) => { setOther(e.target.value); setChoice(''); setError(null) }} />
              )}
            </div>
            {error && <p role="alert" className="rounded bg-red-50 p-2 text-sm text-red-700">{error}</p>}
            <div className="flex gap-2">
              <button type="button" onClick={onClose} disabled={busy} className="min-h-12 flex-1 rounded-xl border border-border">Cancel</button>
              <button type="button" onClick={() => void open()} disabled={busy}
                className="min-h-12 flex-1 rounded-xl bg-brown-btn text-white disabled:opacity-40">{busy ? 'Opening…' : 'Open drawer'}</button>
            </div>
          </>
        )}
      </div>
    </div>
  )
}
```
