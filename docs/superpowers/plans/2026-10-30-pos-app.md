# POS · The POS app (Sub-plan C2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Craft POS, the till as its own installable web app.
- A tablet activates with a code that HQ approves, then staff sign in on a lock screen with their PIN.
- It locks itself after the outlet's idle minutes.
- Only the printing tablet prints.
- It reloads offline from its service worker and picks up new builds only on the lock screen.
- Craft OS `/pos` keeps working unchanged until Sub-plan C3.

**Architecture:**
- **Its own Vite entry.**
  - `vite.pos.config.ts` builds `pos/index.html` → `src/pos/main.tsx` into `dist-pos/`, with `index.html` at the top.
  - The `craft-pos` Vercel project serves it with the same `vercel.json` as Craft OS.
- **Its own Supabase client.**
  - A small Vite plugin hands every module that imports `src/shared/lib/supabase.ts` the POS client, `src/pos/posSupabase.ts`, instead. The till's existing modules therefore run unchanged on the device's session (storage key `craft-pos-auth`).
  - The client's `fetch` announces `pos_ctx()`'s coded errors on `window`.
- **The till is split from Craft OS.**
  - `PosPage.tsx`'s body moves to `PosTill.tsx`, which takes its context as props.
  - `PosPage` becomes the Craft OS wrapper (useAuth, useCan, navigate).
  - `src/pos/PosApp.tsx` runs the same till for the device. The till stays mounted under the lock screen, so unsent items wait for the next person.
- **One SQL function, `pos_whoami()`.** It returns the device, the outlet, the signed-in person, and what that person may do on the tablet.

**Tech Stack:** React 19, Vite 6, TypeScript, Tailwind, Vitest + Testing Library (jsdom), Supabase (Postgres RPCs, Auth, Edge Function `pos-device-activation`), a hand-written service worker. The gates are `npx tsc -b`, `npx vitest run`, `npm run build` and `npm run build:pos`.

**Spec:** `docs/superpowers/specs/2026-10-29-pos-devices-outlets-design.md`:
- §2: activation, PIN login, lock, offline queue;
- §3: the POS as its own app;
- §5: messages and tests;
- the Amendments: all tablets equal, the first screen picks what the device is for, the printing tablet.

## Resolutions (decided while planning, 2026-10-30)

- **`pos_whoami()` (new, SQL).** The roster (`pos_login_roster`, Sub-plan B) gives the device, outlet and session, but not what the signed-in person may do. `pos_whoami()` adds:
  - `canSupervise` (`pos_supervise`): shift reports and the Report menu item;
  - `canUnpair`: `access_settings` with the outlet in scope, the same check as `pos_unpair_this_device`.

  It goes through `pos_ctx()`, so it raises the same coded errors. A staff login gets `device_unpaired`.
- **The client swap is a Vite plugin, not a runtime switch.** In the POS build only, `resolveId` maps the resolved `src/shared/lib/supabase.ts` to `src/pos/posSupabase.ts`. Craft OS's bundle and the Vitest runs are untouched.
- **Coded errors.**
  - `posSupabase`'s `fetch` wrapper reads failed replies. When the message is one of `device_unpaired`, `outlet_closed`, `no_session` or `access_changed`, it fires `craft-pos:context` on `window`. The message is not rewritten.
  - `PosApp` answers the event:
    - `device_unpaired` → the activation screen with the unpaired message;
    - `access_changed` → `pos_end_session('access_changed')` and the lock screen with "Your access here has changed. Ask your manager.";
    - `no_session` / `outlet_closed` → the lock screen, which shows the closed-outlet message from the roster.
  - A till banner may show the raw code for a moment under the lock screen. It is never seen, and the next person's sign-in reloads the till.
- **Locking keeps the till mounted.**
  - The lock screen covers `PosTill`, which gets `locked`. Locking closes the menu, staff panel, report and dialogs, and an open Payment goes home without taking money (spec §2).
  - The order screen and its unsent items stay for whoever signs in next.
  - When `staffId` changes, the till reloads its data.
- **Queued orders.**
  - At Send, `PosTill` stamps the signed-in `staffId` on the order, which goes out as `p_staff_id`.
  - The four context codes are retryable in `toSendResult` (not "rejected"): a queued order waits for the next sign-in.
  - When the device is **unpaired**, its waiting orders are held back (`failedReason = 'Not sent — this device was unpaired'`). A later activation of the same browser cannot resend them on top of what staff re-entered. The activation screen lists them with product names, which are cached at each sign-in because the unpaired device can no longer read the menu (spec §5). The list survives a reload. After activating again, the orders show in the queue strip with Edit and Discard.
- **Lock while offline.**
  - "You're offline — nobody can sign in until the network is back." **Lock anyway** locks the screen at once.
  - The reason is stored (`craft-pos-lock-pending`), and the server session is ended on the next roster read.
- **Reloads.**
  - The device is "activated" when a session is **stored** under `craft-pos-auth`. `getSession()` would answer "none" offline once the hour-long access token has expired.
  - The last roster and `whoami` are cached (`craft-pos-context`), so a tablet that reloads offline opens the till for whoever was signed in.
  - Online, an open server session resumes after a reload, unless a Lock is pending.
- **Unpaired detection** has two signals:
  - the coded error, while the access token lives;
  - Supabase's `SIGNED_OUT` once the banned account's refresh fails.

  Either one leads to the same single switch to the activation screen.
- **Activation.**
  - The first screen offers only **POS** (Amendments), with an optional device name. A customer display is a later choice on that screen.
  - The request and polls go to the Edge Function by `fetch` with the anon key (deployed `--no-verify-jwt`).
  - The waiting request (`code`, `secret`) survives a reload (`craft-pos-activation`).
  - A device approved as a print agent is refused with a message: the POS app does not sign in as it.
  - **A lost approved reply:**
    - The next poll answers `unknown`.
    - The screen says "This request is no longer valid. If HQ already approved it, ask HQ to unpair this device in Devices and approve a new request."
    - The ghost device that HQ then sees on the Devices page keeps any printing role until it is unpaired. This closes Sub-plan B's open point.
- **Printing tablet.**
  - `StaffPanel` runs `PrintHostPanel` only when `prints`. Other tablets show "This tablet does not print. Tickets print on this outlet's printing tablet."
  - The cash drawer opens through the receipt printing, so nothing else changes on the client.
  - Craft OS `/pos` passes `prints` (the staff login prints through the C1 transition).
- **Craft OS `/pos` is unchanged in behaviour.** It keeps Menu, Setting, My PIN and Exit POS. In the POS app:
  - Menu and Setting are hidden (they stay in Craft OS, spec §3);
  - My PIN and Exit POS are gone;
  - Lock, and Unpair this device (for a manager of the outlet), are added.
- **Updates (spec §3).**
  - Every build writes `version.json` and registers `/sw.js?v=<build>`, which caches that build's `index.html` assets.
  - `useAppUpdate` checks `version.json` every 10 minutes and when the network returns. A newer build's worker is registered, downloaded and activated in the background.
  - The app reloads only while nobody is signed in.
  - Pages load network-first, so a relaunch while online also gets the newest build. That is never mid-order.
- **Auth session settings** (Sub-plan B's open point). On dev, `sessions_timebox` and `sessions_inactivity_timeout` are 0 (checked 2026-10-30). Prod is checked at rollout.
- **Ports.** `npm run dev:pos` uses 5179, because 5174 is the `pos-menu-dev` preview. The browser checks use `vite preview` on 5190 and 5191: two origins, so two separate devices.

do $$ begin

  end if;
end $$;

create or replace function pos_whoami() returns jsonb
language plpgsql security definer set search_path = public, pg_temp as $$
declare
  v_ctx record;
  v_dev pos_devices;
begin
  select * into v_ctx from pos_ctx();
  if v_ctx.device_id is null then raise exception 'device_unpaired'; end if;      -- a staff login is no device
  select * into v_dev from pos_devices d where d.id = v_ctx.device_id;
  return jsonb_build_object(
    'deviceId', v_dev.id, 'deviceName', v_dev.name, 'prints', v_dev.prints,
    'outletId', v_ctx.branch_id, 'outletName', (select b.name from branches b where b.id = v_ctx.branch_id),
    'staffId', v_ctx.staff_id, 'staffName', (select s.name from staff s where s.id = v_ctx.staff_id),
    'canSupervise', staff_has_cap(v_ctx.staff_id, 'pos_supervise'),
    'canUnpair', staff_has_cap(v_ctx.staff_id, 'access_settings')
                 and v_ctx.branch_id in (select staff_outlet_scope(v_ctx.staff_id)));
end $$;
revoke all on function pos_whoami() from public, anon;
grant execute on function pos_whoami() to authenticated;

notify pgrst, 'reload schema';
select 'pos app applied' as result;

  fetchBranchCatalogs, fetchOpenBillSummaries, fetchOpenBills, fetchOrderBillId, fetchTables,
  type OpenBillRow, type TableRow,

import { billTitle, targetBill, targetKey, targetTitle, type OrderTarget } from './orderTarget'

export interface TillProps {
  branchId: string
  branchName: string
  /** The signed-in person on a POS tablet: queued orders carry it (spec §2 "Offline queue").
   *  Null for a Craft OS login, whose orders the server records as the caller's. */

  staffName: string
  can: { manageMenu: boolean; supervise: boolean; settings: boolean }
  /** This device prints the outlet's tickets (the POS app: the printing tablet only). */
  prints: boolean
  /** The tablet is locked (POS app): an open Payment goes home and the panels close. Unsent
   *  items stay for whoever signs in and presses Send (spec §2 "What locking keeps"). */
  locked: boolean
  /** Craft OS: Menu and Setting open its back-office pages. */
  onBackOffice?: (path: '/menu' | '/pos/settings') => void
  /** Craft OS: Exit POS, after asking about unsent items. */
  onExit?: () => void
  /** Craft OS: My PIN. */

/** The till — the Feedme-layout POS (docs/superpowers/specs/2026-10-26-pos-feedme-frontend-design.md),
 *  run by Craft OS's /pos (PosPage) and by the POS app. Owns the data every screen shares (tables,
 *  open bills and their summaries, billing config, catalogs, the offline queue, realtime, the shift)
 *  and which screen is up. */
export default function PosTill({ branchId, branchName, staffId, staffName, can, prints, locked, onBackOffice, onExit, myPin = false, onLock, onUnpair }: TillProps) {
  const [tables, setTables] = useState<TableRow[]>([])
  const [bills, setBills] = useState<OpenBillRow[]>([])
  const [summaries, setSummaries] = useState<Map<string, BillSummary>>(new Map())
  const [newBillIds, setNewBillIds] = useState<Set<string>>(new Set())
  const [refreshKey, setRefreshKey] = useState(0)
  const [error, setError] = useState<string | null>(null)
  const [notice, setNotice] = useState<string | null>(null)
  const [screen, setScreen] = useState<Screen>({ kind: 'home' })
  const [menuOpen, setMenuOpen] = useState(false)
  const [staffOpen, setStaffOpen] = useState(false)
  const [printProblems, setPrintProblems] = useState(0)   // the print host's problem count: the bottom bar's badge
  const [pinOpen, setPinOpen] = useState(false)
  const [reportOpen, setReportOpen] = useState(false)
  const [paxFor, setPaxFor] = useState<TableRow | null>(null)
  const [confirm, setConfirm] = useState<ConfirmRequest | null>(null)
  const [stuckNames, setStuckNames] = useState<Map<string, string> | null>(null)
  const [branchCatalogs, setBranchCatalogs] = useState<BranchCatalogs | null>(null)
  const [billing, setBilling] = useState<BillingConfig | null>(null)
  const queue = useOrderQueue()
  const shift = useShiftOpen(refreshKey)
  const reqId = useRef(0)
  const session = useRef(0)
  const screenRef = useRef(screen)                  // late order-screen callbacks check the cashier is still on that session
  screenRef.current = screen
  const draftCount = useRef(0)                      // the order screen's unsent items, for the menu's guard
  const orderSending = useRef(false)                // the order screen is sending: the menu stays shut until it is done
  const openBillIdRef = useRef<string | null>(null)
  // checkout ids this iPad sent per bill: a reopened Payment re-reads with them, so an unsure payment
  // that lands late shows as paid here. Dropped once the bill is paid or no longer open.
  const checkoutIdsByBill = useRef(new Map<string, string[]>())
  // The rejected original stays in the strip until its edited copy is saved; leaving the order
  // screen without sending keeps it, so nothing the cashier confirmed is ever silently dropped.
  const editingFrom = useRef<string | null>(null)

  /** Tables, open bills and their summaries together; resolves with the bills it read (null on failure).
   *  The summaries are not needed to show the tables (settleReload): a failed read keeps the last ones. */
  const reload = useCallback(async (): Promise<OpenBillRow[] | null> => {
    const id = ++reqId.current
    const [t, b, s] = await Promise.allSettled([fetchTables(branchId), fetchOpenBills(branchId), fetchOpenBillSummaries(branchId)])
    const r = settleReload(t, b, s)
    if (!r.ok) {
      if (id === reqId.current) setError(r.error)
      return null
    }
    if (id === reqId.current) {
      setTables(r.tables); setBills(r.bills); setError(null)
      if (r.summaries) setSummaries(r.summaries)
    }
    return r.bills
  }, [branchId])
  useEffect(() => { void reload() }, [reload])
  const bump = useCallback(() => { setRefreshKey((k) => k + 1); void reload() }, [reload])
  useEffect(() => {
    const open = new Set(bills.map((b) => b.id))
    for (const id of checkoutIdsByBill.current.keys()) if (!open.has(id)) checkoutIdsByBill.current.delete(id)
  }, [bills])
  const loadBilling = useCallback(() => {
    fetchBillingConfig(branchId).then(setBilling, (e) => setError(msg(e)))
  }, [branchId])
  useEffect(() => { loadBilling() }, [loadBilling])
  const hasStuck = queue.stuck.length > 0
  useEffect(() => {
    if (hasStuck && !stuckNames) fetchProductNames().then((rows) => setStuckNames(new Map(rows.map((r) => [r.id, r.name]))), () => undefined)
  }, [hasStuck, stuckNames])
  useEffect(() => {
    fetchBranchCatalogs(branchId).then(setBranchCatalogs, (e) => setError(msg(e)))
  }, [branchId])

  const onOrder = useCallback((row: OrderInsert) => {
    if (row.source === 'qr' && row.bill_id !== openBillIdRef.current) setNewBillIds((s) => new Set(s).add(row.bill_id))
    bump()
  }, [bump])
  // another iPad paid, voided, moved or merged a bill: refresh everything on screen
  const rtStatus = usePosRealtime(branchId, { onOrder, onBill: bump, onSweep: bump })

  const orderBill = screen.kind === 'order' ? targetBill(screen.target, bills) : null
  openBillIdRef.current = orderBill?.id ?? null

  // ── navigation ──
  const goHome = () => { editingFrom.current = null; draftCount.current = 0; setScreen({ kind: 'home' }) }
  const openOrder = (target: OrderTarget, lines?: OrderLine[], catalogId?: string | null) => {
    setNotice(null)
    editingFrom.current = null                      // editRejected sets it again after opening
    draftCount.current = lines?.reduce((n, l) => n + l.qty, 0) ?? 0
    setScreen({ kind: 'order', session: ++session.current, target, lines, catalogId })
  }
  /** The order screen of `sess` changed target (retarget): a move or merge onto another bill starts it
   *  again there, without the drafts or the rejected order being edited. A late call from a screen
   *  the cashier already left does nothing. */
  const changeTarget = (sess: number, t: OrderTarget) => {
    const { screen: next, restarted } = retarget(screenRef.current, sess, t)
    if (next === screenRef.current) return
    if (restarted) { editingFrom.current = null; draftCount.current = 0 }
    screenRef.current = next
    setScreen(next)
  }
  /** Back or a finished send from the order screen of `sess`: home, unless the cashier already left it. */
  const homeFrom = (sess: number) => { if (onSession(screenRef.current, sess)) goHome() }
  /** Leave the order screen through the menu or Exit POS: unsent items are asked about first (spec §2). */
  const leave = (go: () => void) => {
    if (screen.kind === 'order' && draftCount.current > 0) {
      setConfirm({ title: discardQuestion(draftCount.current), confirmLabel: 'Discard', danger: true,
        onConfirm: () => { editingFrom.current = null; draftCount.current = 0; go() } })
      return
    }
    go()
  }
  const pickTable = (tableId: string) => {
    const bill = bills.find((b) => b.table_id === tableId)
    if (bill) {
      setNewBillIds((s) => { const n = new Set(s); n.delete(bill.id); return n })
      openOrder({ kind: 'table', tableId, pax: null })
      return
    }
    setPaxFor(tables.find((t) => t.id === tableId) ?? null)     // an empty table: Select pax first
  }
  const pickMenu = (item: MenuItem) => {
    setMenuOpen(false)
    if (item === 'report') { setReportOpen(true); return }
    leave(() => {
      if (item === 'order') goHome()
      else if (item === 'transaction') { editingFrom.current = null; draftCount.current = 0; setScreen({ kind: 'transaction' }) }
      else onBackOffice?.(item === 'menu' ? '/menu' : '/pos/settings')
    })
  }

  // ── the lock (POS app) ──
  // Locking closes what the last person had open; an open Payment goes home without taking money.
  useEffect(() => {
    if (!locked) return
    setMenuOpen(false); setStaffOpen(false); setReportOpen(false); setPaxFor(null); setConfirm(null)
    if (screenRef.current.kind === 'payment') goHome()
  }, [locked])
  // the next person's sign-in: read everything again (calls made while locked were refused)
  const lastStaff = useRef(staffId)
  useEffect(() => {
    if (lastStaff.current === staffId) return
    lastStaff.current = staffId
    bump()
  }, [staffId, bump])

  // ── the queue ──
  // A rejected order is handed straight back to the order screen (cart intact), so drop the queued
  // copy instead of leaving a duplicate in the strip once the cashier fixes and resends.
  const submit = async (o: QueuedOrder) => {
    const res = await queue.submit(staffId ? { ...o, staffId } : o)
    if (res.rejectedReason) await queue.discard(res.clientOrderId)
    else if (editingFrom.current) {
      // the edited copy is now saved on this iPad, so the rejected original can go
      await queue.discard(editingFrom.current)
      editingFrom.current = null
    }
    return res
  }
  const editRejected = (o: QueuedOrder) => {
    const p = padFromRejected(o)
    openOrder(p.target, p.lines, p.catalogId)
    editingFrom.current = o.clientOrderId
  }

  /** Send & pay: the order reached the server → Payment on the bill it landed on. Still only queued
   *  on this iPad, or the lookup failed (offline) → home with QUEUED_NOT_SENT (payOutcome), so
   *  Payment never opens without the order and the cashier is never left on an empty cart. The
   *  lookup and the reload after it share one ~8 s deadline: a stalled network counts as not found. */
  const sendAndPay = async (clientOrderId: string, target: OrderTarget, sess: number) => {
    const wait = deadline(SEND_PAY_WAIT_MS)
    let billId: string | null = null
    let fresh: OpenBillRow[] | null = null
    try {
      billId = await wait.race(fetchOrderBillId(clientOrderId).catch(() => null), null)
      if (!onSession(screenRef.current, sess)) return            // the cashier left meanwhile: no screen jumps
      if (billId) {
        setRefreshKey((k) => k + 1)
        fresh = await wait.race(reload(), null)
        if (!onSession(screenRef.current, sess)) return
      }
    } finally { wait.clear() }
    const out = payOutcome(billId, fresh, target)
    if (out.kind === 'home') { goHome(); setNotice(out.notice); return }
    loadBilling()
    draftCount.current = 0
    setScreen({ kind: 'payment', bill: out.bill, back: out.back })
  }

  const items = menuItems({ manageMenu: can.manageMenu && !!onBackOffice, supervise: can.supervise, settings: can.settings && !!onBackOffice })
  const title = screen.kind === 'home' ? 'Tables'
    : screen.kind === 'order' ? targetTitle(screen.target, orderBill, tables)
    : screen.kind === 'transaction' ? 'Transaction' : 'Payment'
  const current: MenuItem | null = screen.kind === 'transaction' ? 'transaction' : screen.kind === 'payment' ? null : 'order'
  const banners = (

import { createClient } from '@supabase/supabase-js'
import { contextCode, type ContextCode } from '../features/pos/deviceErrors'

/** The POS app's Supabase client (spec §3). vite.pos.config.ts gives it to every module that
 *  imports src/shared/lib/supabase.ts, so the till's code runs on it unchanged. The device's
 *  session lives under its own storage key, apart from any Craft OS login. */

export const POS_STORAGE_KEY = 'craft-pos-auth'
/** Fired on window with the code as `detail` when any call meets a pos_ctx() coded error. */
export const CONTEXT_EVENT = 'craft-pos:context'

/** fetch that announces a coded error in a failed reply (PostgREST: `{ code, message }`). */
export function makePosFetch(base: typeof fetch, announce: (code: ContextCode) => void): typeof fetch {
  return async (input, init) => {
    const res = await base(input, init)
    if (!res.ok) {
      try {
        const code = contextCode(((await res.clone().json()) as { message?: unknown } | null)?.message)
        if (code) announce(code)
      } catch { /* not JSON */ }
    }
    return res
  }
}

export const supabase = createClient(
  import.meta.env.VITE_SUPABASE_URL as string,
  import.meta.env.VITE_SUPABASE_ANON_KEY as string,
  {
    auth: { storageKey: POS_STORAGE_KEY, persistSession: true, autoRefreshToken: true, detectSessionInUrl: false },
    global: {
      fetch: makePosFetch((input, init) => fetch(input, init),
        (code) => window.dispatchEvent(new CustomEvent<ContextCode>(CONTEXT_EVENT, { detail: code }))),
    },
  },
)

// The POS app (spec §3): its own entry, pos/index.html, built to dist-pos/ with index.html at
// the top so the craft-pos Vercel project serves it with the same vercel.json as Craft OS.

 *  they get src/pos/posSupabase.ts instead: the device's own storage key and coded errors. */
function posClient(): Plugin {
  const shared = resolve(root, 'src/shared/lib/supabase.ts')
  const pos = resolve(root, 'src/pos/posSupabase.ts')

    name: 'craft-pos-client',

    name: 'craft-pos-version',

    },
  }
}

```js
// Craft POS service worker (spec §3 "Install and offline launch"). It is registered as
// /sw.js?v=<build>: each build gets its own cache, filled at install from the assets that
// index.html names, so a tablet that reloads with no network still opens the POS and its
// offline queue. Pages load network-first; assets come from the cache. Supabase calls go
// to another origin and pass straight through.
const VERSION = new URL(self.location.href).searchParams.get('v') || 'dev'
const CACHE = `craft-pos-${VERSION}`
const FILES = ['/manifest.webmanifest', '/icons/pos-180.png', '/icons/pos-192.png', '/icons/pos-512.png']

self.addEventListener('install', (event) => {
  event.waitUntil((async () => {
    const cache = await caches.open(CACHE)
    const page = await fetch('/', { cache: 'reload' })
    if (!page.ok) throw new Error(`index.html: ${page.status}`)
    const html = await page.clone().text()
    await cache.put('/', page)
    const assets = [...html.matchAll(/(?:src|href)="(\/assets\/[^"]+)"/g)].map((m) => m[1])
    await cache.addAll([...FILES, ...assets])
    await self.skipWaiting()
  })())
})

self.addEventListener('activate', (event) => {
  event.waitUntil((async () => {
    for (const key of await caches.keys()) if (key.startsWith('craft-pos-') && key !== CACHE) await caches.delete(key)
    await self.clients.claim()
  })())
})

self.addEventListener('fetch', (event) => {
  const req = event.request
  const url = new URL(req.url)
  if (req.method !== 'GET' || url.origin !== self.location.origin) return
  if (req.mode === 'navigate') {
    event.respondWith(fetch(req).catch(async () => (await caches.match('/', { cacheName: CACHE })) ?? Response.error()))
  } else if (url.pathname.startsWith('/assets/') || FILES.includes(url.pathname)) {
    event.respondWith(caches.match(req, { cacheName: CACHE }).then((hit) => hit ?? fetch(req)))
  }
})
```

/** Auto-lock (spec §2): the session ends after `minutes` with no touch. Time spent offline does
 *  not count — nobody could sign in again until the network is back. */

export interface IdleState { idleMs: number; lastTick: number }

export const idleStart = (now: number): IdleState => ({ idleMs: 0, lastTick: now })

/** A touch or key press starts the period again. */
export const idleTouch = (now: number): IdleState => idleStart(now)

/** Time passes; it is counted only while online. */
export function idleTick(s: IdleState, now: number, online: boolean): IdleState {
  return { idleMs: online ? s.idleMs + Math.max(0, now - s.lastTick) : s.idleMs, lastTick: now }
}

export const idleDue = (s: IdleState, minutes: number): boolean => s.idleMs >= minutes * 60_000

/** Activation (spec §2 "Activation flow"): the tablet asks the Edge Function
 *  pos-device-activation for a code, shows it, and polls every 5 s until HQ approves or
 *  rejects it in Craft OS → Devices. The approved reply carries the device's sign-in once. */

export type Platform = 'ipad' | 'android' | 'other'

/** iPadOS 13+ says "Macintosh" but has a touch screen. */
export function detectPlatform(userAgent: string, maxTouchPoints: number): Platform {
  if (/iPad/.test(userAgent) || (/Macintosh/.test(userAgent) && maxTouchPoints > 1)) return 'ipad'
  if (/Android/.test(userAgent)) return 'android'
  return 'other'
}

export interface Pending { code: string; secret: string; expiresAt: string; name: string | null }

export type PollReply =
  | { status: 'pending' | 'rejected' | 'expired' | 'unknown' }
  | { status: 'approved'; deviceId: string; email: string; password: string; branchId: string; kind: string; name: string }

export type EndReason = 'rejected' | 'expired' | 'unknown' | 'wrong_kind' | 'unpaired'

export type ActivationState =
  | { kind: 'choose' }                                    // the first screen: what this device is for
  | { kind: 'requesting' }
  | { kind: 'waiting'; pending: Pending; note: string | null }
  | { kind: 'signing_in'; email: string; password: string }
  | { kind: 'ended'; reason: EndReason }
  | { kind: 'error'; message: string }

export const POLL_MS = 5_000

/** The next state after a poll reply. Only 'waiting' keeps polling. */
export function afterPoll(pending: Pending, reply: PollReply): ActivationState {
  switch (reply.status) {
    case 'pending': return { kind: 'waiting', pending, note: null }
    case 'approved':
      return reply.kind === 'pos'
        ? { kind: 'signing_in', email: reply.email, password: reply.password }
        : { kind: 'ended', reason: 'wrong_kind' }
    default: return { kind: 'ended', reason: reply.status }
  }
}

export const isPolling = (s: ActivationState): boolean => s.kind === 'waiting'

export const ENDED: Record<EndReason, string> = {
  rejected: 'This request was rejected.',
  expired: 'This request expired.',

  unknown: 'This request is no longer valid. If HQ already approved it, ask HQ to unpair this device in Devices and approve a new request.',
  wrong_kind: 'HQ approved this device as a print agent. Ask HQ to unpair it in Devices and approve it again as POS.',
  unpaired: 'This device was unpaired. Ask HQ to activate it again.',
}

const KEY = 'craft-pos-activation'

export function savePending(store: Storage, p: Pending): void { store.setItem(KEY, JSON.stringify(p)) }

 *  (so a reload with no network still opens the till for whoever was signed in, spec §3), a
 *  Lock that could not reach the server yet, and product names for the unpaired screen. */
import type { QueueStore, QueuedOrder } from '../features/pos/offline/orderQueue'
import type { RosterReply } from './roster'
import type { WhoAmI } from './sessionApi'

export interface Cached { roster: RosterReply; who: WhoAmI | null }

const CONTEXT = 'craft-pos-context'
const LOCK = 'craft-pos-lock-pending'
const NAMES = 'craft-pos-product-names'

function read<T>(store: Storage, key: string): T | null {
  try { return JSON.parse(store.getItem(key) ?? 'null') as T | null } catch { return null }
}

export const saveContext = (store: Storage, c: Cached): void => store.setItem(CONTEXT, JSON.stringify(c))
export const loadContext = (store: Storage): Cached | null => read<Cached>(store, CONTEXT)

export type LockReason = 'locked' | 'idle' | 'access_changed'
/** A Lock pressed offline: the server session is ended on the next roster read. */
export const setPendingLock = (store: Storage, r: LockReason): void => store.setItem(LOCK, r)
export const clearPendingLock = (store: Storage): void => store.removeItem(LOCK)
export const pendingLock = (store: Storage): LockReason | null => {
  const r = store.getItem(LOCK)
  return r === 'locked' || r === 'idle' || r === 'access_changed' ? r : null
}

export const saveProductNames = (store: Storage, rows: { id: string; name: string }[]): void =>
  store.setItem(NAMES, JSON.stringify(rows.map((r) => [r.id, r.name])))
export const loadProductNames = (store: Storage): Map<string, string> =>
  new Map(read<[string, string][]>(store, NAMES) ?? [])

/** Everything about this device's pairing goes when it is unpaired. */
export function forgetContext(store: Storage): void {
  store.removeItem(CONTEXT)
  store.removeItem(LOCK)
}

export const UNPAIRED_REASON = 'Not sent — this device was unpaired'

/** The device was unpaired: the orders still waiting are held back (never resent by
 *  themselves), so staff enter them again and a later activation cannot double them.
 *  They stay in the queue's list with Edit and Discard. Returns every held order, oldest first. */
export async function holdQueued(store: QueueStore): Promise<QueuedOrder[]> {
  for (const o of await store.all()) if (!o.failedReason) await store.put({ ...o, failedReason: UNPAIRED_REASON })
  return (await store.all()).sort((a, b) => a.queuedAt - b.queuedAt)
}

import { useEffect, useRef } from 'react'
import { idleDue, idleStart, idleTick, idleTouch } from './idleLock'

const TICK_MS = 5_000

/** Calls onIdle once after `minutes` with no touch or key press while `active` (someone is
 *  signed in). Offline time does not count (idleLock.ts). */
export function useIdleLock(minutes: number, active: boolean, onIdle: () => void): void {
  const cb = useRef(onIdle)
  cb.current = onIdle
  useEffect(() => {
    if (!active) return
    let s = idleStart(Date.now())
    const touch = () => { s = idleTouch(Date.now()) }
    const timer = window.setInterval(() => {
      s = idleTick(s, Date.now(), navigator.onLine)
      if (idleDue(s, minutes)) { window.clearInterval(timer); cb.current() }
    }, TICK_MS)
    window.addEventListener('pointerdown', touch, true)
    window.addEventListener('keydown', touch, true)
    return () => {
      window.clearInterval(timer)
      window.removeEventListener('pointerdown', touch, true)
      window.removeEventListener('keydown', touch, true)
    }
  }, [minutes, active])
}

```ts
import { useEffect, useState } from 'react'
import { newerBuild, RUNNING_BUILD, swUrl } from './appUpdate'

const CHECK_MS = 10 * 60_000

/** True once a newer build is downloaded: its service worker is installed and active, so a
 *  reload opens it even with no network. The app reloads only on the lock screen (spec §3). */
export function useAppUpdate(): boolean {
  const [ready, setReady] = useState(false)
  useEffect(() => {
    if (!import.meta.env.PROD || !('serviceWorker' in navigator)) return
    let stopped = false
    let busy = false
    const check = async () => {
      if (busy || stopped) return
      busy = true
      try {
        const res = await fetch(`/version.json?t=${Date.now()}`, { cache: 'no-store' })
        const build = newerBuild(res.ok ? await res.json() : null, RUNNING_BUILD)
        if (!build) return
        await activated(await navigator.serviceWorker.register(swUrl(build)))
        if (!stopped) setReady(true)
      } catch { /* offline or a failed download: the next check tries again */ } finally { busy = false }
    }
    void check()
    const timer = window.setInterval(() => void check(), CHECK_MS)
    window.addEventListener('online', check)
    return () => { stopped = true; window.clearInterval(timer); window.removeEventListener('online', check) }
  }, [])
  return ready
}

function activated(reg: ServiceWorkerRegistration): Promise<void> {
  const w = reg.installing ?? reg.waiting
  if (!w) return Promise.resolve()
  return new Promise((done, fail) => {
    w.addEventListener('statechange', () => {
      if (w.state === 'activated') done()
      else if (w.state === 'redundant') fail(new Error('The update did not install'))
    })
  })
}

  endSession, fetchRoster, fetchWhoAmI, forgetDevice, hasDeviceSession, unpairThisDevice, type WhoAmI,
} from './sessionApi'
import { useAppUpdate } from './useAppUpdate'
import { useIdleLock } from './useIdleLock'

const msg = (e: unknown) => (e instanceof Error ? e.message : String(e))
const ACCESS_CHANGED = 'Your access here has changed. Ask your manager.'
const ROSTER_MS = 60_000

type Phase =
  | { kind: 'boot' }
  | { kind: 'activation'; start: ActivationState; unsent: QueuedOrder[] }
  | { kind: 'device' }

function useOnline(): boolean {
  const [online, setOnline] = useState(navigator.onLine)
  useEffect(() => {
    const on = () => setOnline(true)
    const off = () => setOnline(false)
    window.addEventListener('online', on)
    window.addEventListener('offline', off)
    return () => { window.removeEventListener('online', on); window.removeEventListener('offline', off) }
  }, [])
  return online
}

/** Craft POS (spec §2, §3): activation → lock screen ⇄ the till. The till mounts at the first
 *  sign-in and stays mounted under the lock screen, so unsent items wait for the next person. */
export default function PosApp() {
  const [phase, setPhase] = useState<Phase>({ kind: 'boot' })
  const [roster, setRoster] = useState<RosterReply | null>(null)
  const [who, setWho] = useState<WhoAmI | null>(null)          // null: locked
  const [till, setTill] = useState<WhoAmI | null>(null)        // the last signed-in context: keeps the till mounted
  const [lockNote, setLockNote] = useState<string | null>(null)
  const [loadError, setLoadError] = useState<string | null>(null)
  const [confirm, setConfirm] = useState<ConfirmRequest | null>(null)
  const online = useOnline()
  const updateReady = useAppUpdate()
  const whoRef = useRef(who)
  whoRef.current = who
  const phaseRef = useRef(phase)
  phaseRef.current = phase

  const signedIn = (w: WhoAmI | null) => {
    setWho(w)
    if (w) { setTill(w); setLockNote(null) }
  }

  /** The roster and, when someone is signed in, who it is. A Lock that could not reach the
   *  server is finished first. Offline, the last context on this tablet is used. */
  const refresh = useCallback(async () => {
    try {
      let r = await fetchRoster()
      const pending = pendingLock(localStorage)
      if (pending && r.session) { await endSession(pending); r = await fetchRoster() }
      clearPendingLock(localStorage)
      const w = r.session ? await fetchWhoAmI() : null
      setRoster(r); signedIn(w); setLoadError(null)
      saveContext(localStorage, { roster: r, who: w })
    } catch (e) {
      if (phaseRef.current.kind !== 'device') return                 // unpaired meanwhile (the event)
      const c = loadContext(localStorage)
      if (c) { setRoster(c.roster); if (!pendingLock(localStorage) && !whoRef.current) signedIn(c.who) }
      setLoadError(msg(e))
    }
  }, [])

  const toActivation = useCallback(async (start: ActivationState, hold: boolean) => {
    if (phaseRef.current.kind === 'activation') return
    phaseRef.current = { kind: 'activation', start, unsent: [] }        // once, whichever signal comes first
    const unsent = hold ? await holdQueued(createIdbStore()).catch(() => []) : []
    await forgetDevice().catch(() => undefined)
    forgetContext(localStorage)
    setWho(null); setTill(null); setRoster(null)
    setPhase({ kind: 'activation', start, unsent })
  }, [])

  // boot
  useEffect(() => {
    void (async () => {
      if (!hasDeviceSession()) {
        const p = loadPending(localStorage)
        // orders held back when this tablet was unpaired stay listed until it is activated again
        const unsent = (await createIdbStore().all().catch(() => [] as QueuedOrder[]))
          .filter((o) => o.failedReason === UNPAIRED_REASON).sort((a, b) => a.queuedAt - b.queuedAt)
        setPhase({ kind: 'activation', start: p ? { kind: 'waiting', pending: p, note: null } : { kind: 'choose' }, unsent })
        return
      }
      setPhase({ kind: 'device' })
      await refresh()
    })()
  }, [refresh])

  const lock = useCallback(async (reason: LockReason, note: string | null = null) => {
    setWho(null); setLockNote(note)
    setPendingLock(localStorage, reason)
    try { await endSession(reason); clearPendingLock(localStorage) } catch { /* offline: ended on the next roster read */ }
    await refresh()
  }, [refresh])

  // a coded error from any call (posSupabase.ts)
  useEffect(() => {
    const on = (e: Event) => {
      const code = (e as CustomEvent<ContextCode>).detail
      if (code === 'device_unpaired') {
        if (phaseRef.current.kind === 'device') void toActivation({ kind: 'ended', reason: 'unpaired' }, true)
      } else if (code === 'access_changed') {
        if (whoRef.current) void lock('access_changed', ACCESS_CHANGED)
      } else if (whoRef.current) {                                    // no_session, outlet_closed: back to the lock screen
        setWho(null)
        void refresh()
      }
    }
    window.addEventListener(CONTEXT_EVENT, on)
    return () => window.removeEventListener(CONTEXT_EVENT, on)
  }, [lock, refresh, toActivation])

  // an unpaired device's token can no longer refresh: Supabase signs it out
  useEffect(() => {
    const { data } = supabase.auth.onAuthStateChange((event) => {
      if (event === 'SIGNED_OUT' && phaseRef.current.kind === 'device') void toActivation({ kind: 'ended', reason: 'unpaired' }, true)
    })
    return () => data.subscription.unsubscribe()
  }, [toActivation])

  // while locked: the roster stays fresh; back online: the session token too
  useEffect(() => {
    if (phase.kind !== 'device' || who) return
    const timer = window.setInterval(() => void refresh(), ROSTER_MS)
    return () => window.clearInterval(timer)
  }, [phase.kind, who, refresh])
  useEffect(() => {
    if (!online || phase.kind !== 'device') return
    void supabase.auth.getSession().then(() => refresh())
  }, [online, phase.kind, refresh])

  // product names for the unpaired screen's list
  const whoId = who?.staffId
  useEffect(() => {
    if (whoId) fetchProductNames().then((rows) => saveProductNames(localStorage, rows), () => undefined)
  }, [whoId])

  // a downloaded update opens on the lock screen only, never mid-order
  useEffect(() => {
    if (updateReady && !who) window.location.reload()
  }, [updateReady, who])

  useIdleLock(roster?.idleLockMinutes ?? 10, who !== null, () => void lock('idle'))

  if (phase.kind === 'boot') return <div className="flex min-h-dvh items-center justify-center bg-cream text-brown-muted">Craft POS</div>
  if (phase.kind === 'activation') {
    return <ActivationScreen start={phase.start} unsent={phase.unsent} names={loadProductNames(localStorage)}
      onActivated={() => { setPhase({ kind: 'device' }); void refresh() }} />
  }

  const requestLock = () => {
    if (online) { void lock('locked'); return }
    setConfirm({ title: "You're offline — nobody can sign in until the network is back.", confirmLabel: 'Lock anyway',
      onConfirm: () => void lock('locked') })
  }
  const requestUnpair = () => setConfirm({
    title: 'Unpair this device?', message: 'It stops working until HQ activates it again.', confirmLabel: 'Unpair', danger: true,
    onConfirm: async () => {
      try { await unpairThisDevice(); await toActivation({ kind: 'choose' }, false) }
      catch (e) { setLoadError(msg(e)) }
    },
  })

  return (
    <>
      {till && (
        <PosTill branchId={till.outletId} branchName={till.outletName} staffId={who?.staffId ?? till.staffId}
          staffName={who?.staffName ?? till.staffName}
          can={{ manageMenu: false, supervise: who?.canSupervise ?? false, settings: false }}
          prints={roster?.device.prints ?? till.prints} locked={who === null}
          onLock={requestLock} onUnpair={who?.canUnpair ? requestUnpair : undefined} />
      )}
      {!who && (
        <LockScreen roster={roster} note={lockNote} offline={!online} loadError={loadError}
          onSignedIn={() => void refresh()} onRefresh={() => void refresh()} />
      )}
      {confirm && (
        <ConfirmDialog {...confirm} onCancel={() => setConfirm(null)}
          onConfirm={() => { const c = confirm; setConfirm(null); c.onConfirm() }} />
      )}
    </>
  )
}
```
