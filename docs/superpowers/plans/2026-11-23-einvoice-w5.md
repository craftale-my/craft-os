# MyInvois E-invoice W5 — Catch-up and Automation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the e-invoice skeleton up to the POS as it is now (discounts, takeaway lines, business days), stop double reporting at cut-over with a per-outlet start date, and run everything daily without the owner: refresh, monthly consolidation, credit notes for refunds, the RM 10,000 guard, a reconciliation check — spec W5.1–W5.7 and W5.9 (W5.8 is out of scope).

**Architecture:** One SQL migration (two tasks) adds `pos_ledger_lines(uuid[])` — the ledger's per-line figures and SST split for any set of bills — and re-creates `pos_report_ledger` on it, then `branches.einvoice_from` with its guard, the job tables, and the service-role selections the Edge Function reads (bill source, month's bills, refunds due, reconciliation source). A second small SQL file installs `pg_net`, `einvoice_call_job(text)` (reads the job secret and the function URL from Vault) and the `pg_cron` job. In the Edge Function, the pure builders (`ubl.ts`, `documents.ts`) turn ledger lines and bill mixes into checked documents, `job.ts` decides the daily run over injected steps, `reconcile.ts` compares built documents with the bills and Reports → Overview, and `index.ts` only wires them to the database and LHDN, with two job-secret actions (`run`, `reconcile`). The E-invoice screen gains per-outlet start dates, bills over RM 10,000 with a buyer form, stopped attempts with Retry and the daily runs; the banner covers the four W5.7 cases.

**Tech Stack:** Supabase Postgres (sql / plpgsql functions, triggers, RLS, `pg_cron` 1.6.4, `pg_net`, `supabase_vault`), Supabase Edge Functions (Deno, `jsr:@supabase/supabase-js@2`), React 19 + TypeScript + Vite, Tailwind, Vitest + Testing Library (jsdom per file).

**Spec:** `docs/superpowers/specs/2026-10-26-myinvois-einvoice-design.md`, section "W5 — catch-up and automation (2026-11-23)" (W5.1–W5.9; the owner asked Claude to settle the small decisions). The earlier sections describe the skeleton that exists.

## Decisions (where the spec is silent or the code forces a choice)

Each is settled as stated; nothing else departs from the spec. LHDN field formats stay **unverified until the first sandbox submission** (W5.8) and do not block anything here.

1. **Shared ledger lines.** `pos_ledger_lines(p_bill_ids uuid[])` is the one function (W5.2). `pos_report_ledger` is re-created to read its lines from it (output unchanged: its own verify must still pass, and V1 compares the two). `pos_report_lines` is left as it is (Products and SST reports still use it); `pos_ledger_lines` repeats its line expressions on purpose. Re-running `migration-2026-11-18-pos-reports.sql` later puts back the inline ledger, which gives the same output.
2. **Single invoice lines** (W5.2): one line per item line; `allowanceSen` = gross − net (catalog + item discount + bill share, sent as one `AllowanceCharge` with `ChargeIndicator false`, reason `Discount`); `chargeSen` = the takeaway packaging fee (`ChargeIndicator true`, reason `Takeaway packaging`), taxed with the line; tax = the ledger's `sst_sen` at `tax_rate_bp` (the line's rate when the bill has an SST group of that rate, else 0 → tax type `06`). Service charge and rounding stay whole-document amounts.
3. **Consolidated lines** (W5.2): per business day, one line per SST rate (`Receipts A – B (n), SST 6%`), one `…, no SST` line for the untaxed goods and one `…, service charge` line, classification `004`, qty 1. (The skeleton's per-day line charge is gone; a day's untaxed amounts and service charge are their own lines.) A day's goods = Σ (subtotal − bill discount + packaging), so discounted bills add up.
4. **The month** is the business-day month (06:00–05:59 MYT, `pos_business_day`). A month "has ended" after 06:00 MYT on the 1st; the job runs at 07:00 MYT (`0 23 * * *` UTC). The consolidated invoice's period starts on the later of the month's 1st and the outlet's start date.
5. **Start date** (W5.3): only HQ (`all_branches` + `access_settings`, as for an outlet's kind and dates) sets `branches.einvoice_from`, through `einvoice_set_outlet_start` or a direct update; the trigger `branches_einvoice_from_guard` enforces both rules for every writer. A "live document" is `draft`, `submitted` or `valid`. Future dates are allowed (a planned cut-over). `einvoice_create_document` also refuses any bill (or refunded bill) that is not paid, belongs to another outlet, or is before the outlet's start date — defence in depth.
6. **RM 10,000** (W5.6) = `total_sen > 1000000`. Such a bill is never consolidated and `submit_bill` refuses it without a buyer ("A bill over RM 10,000 needs the buyer's details").
7. **Refund split** (W5.5): a full refund copies the bill's mix exactly (rounding included). A partial refund is split by `allocate` (largest remainder) over [each SST group's base + tax, the untaxed goods, the service charge]; each group's share is cut into tax = round(share × tax ÷ (base + tax)), capped at the group's tax, and base = the rest; rounding 0. Each credit note's tax therefore never exceeds the bill's.
8. **When credit notes go out:** only once the original document is `valid` (its LHDN UUID is the reference). Single credit notes: every daily run. Consolidated credit notes: every daily run, for each outlet and each business month **before the current one** that has refunds due (by the refund's business day); the refunds of bills from the month that just closed follow a day or two after their consolidated invoice is validated.
9. **Credit note fields:** `InvoiceTypeCode` `02` for both kinds; `BillingReference` → `InvoiceDocumentReference` { `ID` = original code number, `UUID` = original LHDN UUID }, one per distinct original document; single credit note buyer = the original invoice's buyer (else General Public), classification `022`; consolidated credit note buyer General Public, classification `004`, period = the refunds' month. Code numbers `CN-…` / `CCN-…` as the skeleton makes them.
10. **Attempts** (W5.4 step 2): `einvoice_job_attempts` keeps one row per key — `CON|<outlet>|YYYY-MM`, `CCN|<outlet>|YYYY-MM`, `CN|<refund id>` — with a failure count. A refusal (nothing created) or an LHDN rejection adds one; LHDN marking a consolidated document `invalid` on refresh adds one; a success after failures resets it to 0. At 3 the daily run skips the key and the banner shows it. Retry on the screen calls `consolidate` (manual, counted the same way) or `credit_notes` (which ignores the stop).
11. **Drafts** that never reached LHDN (network, LHDN down) are resent by the daily run's step 1 along with refreshing `submitted` documents.
12. **Not set up** = what `readyClient` refuses: no MyInvois credentials, missing company details, or `environment = production` (unsigned v1.0 production is not built). The run then writes one `not_set_up` row and calls nothing; the banner shows it only when the row's environment is `production`.
13. **Job authentication:** `run` and `reconcile` are the only job actions; they need header `x-einvoice-job-secret` equal to function secret `EINVOICE_JOB_SECRET` (constant-time compare, at least 32 characters). Every other action keeps the JWT + `access_settings` check, now done in code because the function is deployed with `--no-verify-jwt`.
14. **Function URL lives in Vault** (secret `einvoice_function_url`), next to `einvoice_job_secret`, not in `einvoice_settings`: `access_settings` users can update `einvoice_settings`, and a URL there could send the job secret anywhere.
15. **Reconciliation** (W5.9) is the job action `reconcile`: it builds (never submits) every paid bill's own e-invoice and every outlet-month's consolidated invoice from `einvoice_reconcile_source(from, to)` and returns the comparison. The controller triggers it from the SQL editor with `select einvoice_call_job('reconcile')` and reads the answer from `net._http_response`, so nobody needs the job secret after it is set.
16. **Bills are never re-priced:** documents read `bills.totals` as frozen at checkout. A paid bill without totals is refused ("This bill has no checkout totals"); the reconciliation lists any.
17. **Who sees what:** the screen's new reads are RLS-filtered tables (`einvoice_job_runs`, `einvoice_job_attempts`: `access_settings`) and `einvoice_large_bills()` (returns nothing without `access_settings`).

-- ── E1. The sales ledger's lines, shared (spec W5.2) ────────────────────────
-- One row per live line of the given paid bills: pos_report_lines' figures (gross, catalog / item /
-- bill-share discount, net after discounts as frozen in bills.totals.lines; a bill without them: price ×
-- qty, no discount), the packaging fee of a takeaway line, the SST base (net + that fee), the rate it is
-- taxed at (its own rate when the bill has an SST group of that rate, else 0: a 0% line or an outlet not
-- registered) and its SST: its share of the group, by largest remainder on the SST base (floors first, the
-- sen left to the largest remainders, ties by order item id), so the lines add up to the group. Internal.
create or replace function pos_ledger_lines(p_bill_ids uuid[])
returns table (item_id uuid, bill_id uuid, branch_id uuid, bill_no text, bday date, name text, qty integer,
               unit_price_sen integer, sst_rate_bp integer, gross_sen integer, catalog_discount_sen integer,
               item_discount_sen integer, bill_share_sen integer, net_sen integer, takeaway_fee_sen integer,
               sst_base_sen integer, tax_rate_bp integer, sst_sen integer)
language sql stable security definer set search_path = public, pg_temp as $$
  with pb as (
    select b.* from bills b where b.id = any (p_bill_ids) and b.status = 'paid'),
  ln as (
    select oi.id as item_id, pb.id as bill_id, pb.branch_id, pb.bill_no, pos_business_day(pb.closed_at) as bday,
           oi.name_snapshot as name, oi.qty, oi.unit_price_sen, oi.sst_rate_bp,
           oi.unit_price_sen * oi.qty as gross_sen,
           coalesce((l.v->>'catalogDiscountSen')::integer, 0) as catalog_discount_sen,
           coalesce((l.v->>'itemDiscountSen')::integer, 0) as item_discount_sen,
           coalesce((l.v->>'billShareSen')::integer, 0) as bill_share_sen,
           coalesce((l.v->>'netSen')::integer, oi.unit_price_sen * oi.qty) as net_sen,
           case when coalesce(oi.order_type, pb.order_type) = 'takeaway' then oi.takeaway_fee_sen * oi.qty else 0 end
             as takeaway_fee_sen
      from pb
      join order_items oi on oi.bill_id = pb.id and oi.voided_at is null
      left join lateral (
        select x.v from jsonb_array_elements(coalesce(pb.totals->'lines', '[]'::jsonb)) as x(v)
         where x.v->>'id' = oi.id::text) l on true),
  grp as (
    select pb.id as bill_id, (g.v->>'rateBp')::integer as rate_bp, (g.v->>'amountSen')::bigint as amt
      from pb cross join jsonb_array_elements(coalesce(pb.totals->'sstGroups', '[]'::jsonb)) as g(v)),
  w as (
    select ln.*, ln.net_sen + ln.takeaway_fee_sen as sst_base_sen, grp.rate_bp as group_rate_bp,
           coalesce(grp.amt, 0) as amt,
           sum(ln.net_sen + ln.takeaway_fee_sen) over (partition by ln.bill_id, ln.sst_rate_bp) as base_total
      from ln
      left join grp on grp.bill_id = ln.bill_id and grp.rate_bp = ln.sst_rate_bp),
  fl as (
    select w.*,
           case when w.amt > 0 and w.base_total > 0 then (w.amt * w.sst_base_sen) / w.base_total else 0 end as floor_sst,
           case when w.amt > 0 and w.base_total > 0 then (w.amt * w.sst_base_sen) % w.base_total else 0 end as rem
      from w),
  shares as (
    select fl.*,
           fl.amt - sum(fl.floor_sst) over (partition by fl.bill_id, fl.sst_rate_bp) as left_over,
           row_number() over (partition by fl.bill_id, fl.sst_rate_bp order by fl.rem desc, fl.item_id) as rk
      from fl)
  select s.item_id, s.bill_id, s.branch_id, s.bill_no, s.bday, s.name, s.qty, s.unit_price_sen, s.sst_rate_bp,
         s.gross_sen, s.catalog_discount_sen, s.item_discount_sen, s.bill_share_sen, s.net_sen, s.takeaway_fee_sen,
         s.sst_base_sen,
         case when s.group_rate_bp > 0 then s.group_rate_bp else 0 end,
         (s.floor_sst + case when s.rk <= s.left_over then 1 else 0 end)::integer
    from shares s
$$;

-- einvoice_from: the first business day we report for the outlet; null = we do not report it (Feedme still
-- does). Only HQ (all_branches + access_settings, as for an outlet's kind and dates) changes it — no signed-in
-- user (the SQL editor, the service role) passes. Free to set or move later; moving it earlier or clearing it
-- is refused once the outlet has a live document (draft, submitted or valid).
alter table branches add column if not exists einvoice_from date;

create or replace function branches_einvoice_from_guard() returns trigger
language plpgsql security definer set search_path = public, pg_temp as $$
begin
  if new.einvoice_from is not distinct from old.einvoice_from then
    return new;
  end if;
  if auth.uid() is not null and not (has_menu_cap('all_branches') and has_menu_cap('access_settings')) then
    raise exception 'Only HQ can change when an outlet''s e-invoices start.';
  end if;
  if old.einvoice_from is not null
     and (new.einvoice_from is null or new.einvoice_from < old.einvoice_from)
     and exists (select 1 from einvoice_documents d
                  where d.branch_id = new.id and d.status in ('draft', 'submitted', 'valid')) then
    raise exception 'E-invoices were already sent for this outlet: the start date can only move later.';
  end if;
  return new;
end $$;

create or replace function einvoice_create_document(p_doc jsonb, p_bill_ids uuid[], p_refund_ids uuid[])

language plpgsql security definer set search_path = public, pg_temp as $$
declare
  v_id   uuid := gen_random_uuid();
  v_kind text := p_doc->>'kind';
  v_row  einvoice_documents;
begin
  if exists (                                                                                     -- W5
    select 1
      from bills b
      join branches br on br.id = b.branch_id
     where (b.id = any (coalesce(p_bill_ids, '{}'))
            or b.id in (select r.bill_id from refunds r where r.id = any (coalesce(p_refund_ids, '{}'))))

language sql stable security definer set search_path = public, pg_temp as $$
  with pb as (
    select b.* from bills b
     where b.status = 'paid'
       and b.closed_at >= (p_from + time '06:00') at time zone 'Asia/Kuala_Lumpur'
       and b.closed_at <  (p_to + 1 + time '06:00') at time zone 'Asia/Kuala_Lumpur'),
  bl as (select * from einvoice_bill_lines(array(select pb.id from pb))),
  m as (select distinct pb.branch_id, date_trunc('month', pos_business_day(pb.closed_at)::timestamp)::date as first_day
          from pb)
  select jsonb_build_object(
    'bills', coalesce((
      select jsonb_agg(jsonb_build_object('id', pb.id, 'branchId', pb.branch_id, 'billNo', pb.bill_no,
                                          'day', pos_business_day(pb.closed_at), 'totalSen', pb.total_sen,
                                          'totals', pb.totals, 'lines', coalesce(bl.lines, '[]'::jsonb))
                       order by pb.closed_at, pb.id)
        from pb left join bl on bl.bill_id = pb.id), '[]'::jsonb),
    'months', coalesce((
      select jsonb_agg(jsonb_build_object(
               'branchId', m.branch_id, 'month', to_char(m.first_day, 'YYYY-MM'),
               'overviewSen', (pos_report_cards(array[m.branch_id],
                                                (m.first_day + time '06:00') at time zone 'Asia/Kuala_Lumpur',
                                                ((m.first_day + interval '1 month')::date + time '06:00')
                                                  at time zone 'Asia/Kuala_Lumpur')->>'nettSen')::bigint)
             order by m.first_day, m.branch_id)
        from m), '[]'::jsonb))
$$;

/**
 * Split `total` over `weights` in proportion, whole sen, largest remainder first,
 * so the parts always add back to `total` (ties go to the earlier part).
 */
export function allocate(total: number, weights: number[]): number[] {
  const sum = weights.reduce((a, b) => a + b, 0)
  if (sum === 0) return weights.map((_, i) => (i === 0 ? total : 0))
  const exact = weights.map((w) => (total * w) / sum)
  const parts = exact.map(Math.floor)
  let left = total - parts.reduce((a, b) => a + b, 0)
  const order = exact.map((e, i) => ({ i, r: e - Math.floor(e) })).sort((a, b) => b.r - a.r || a.i - b.i)
  for (const { i } of order) {
    if (left <= 0) break
    parts[i] += 1
    left -= 1
  }
  return parts
}

/**
 * A paid bill as invoice lines, straight from the sales ledger: one line per item line with its
 * discounts as an allowance, a takeaway line's packaging as a charge, and the SST the ledger gave it.
 * The service charge and the rounding stay whole-document amounts.
 */
export function ledgerBillLines(lines: LedgerLine[], totals: BillTotals): {
  lines: DocLine[]; docChargeSen: number; roundingSen: number
} {
  if (lines.length === 0) throw new Error('The bill has no live lines')
  const out = lines.map((l): DocLine => {
    if (l.grossSen !== l.qty * l.unitPriceSen) throw new Error(`${l.name}: gross ${l.grossSen} sen is not ${l.qty} × ${l.unitPriceSen}`)
    if (l.sstBaseSen !== l.netSen + l.takeawayFeeSen) throw new Error(`${l.name}: SST base ${l.sstBaseSen} sen is not net + packaging`)
    return {
      description: l.name, classification: '022', qty: l.qty, unitPriceSen: l.unitPriceSen,
      allowanceSen: l.grossSen - l.netSen, chargeSen: l.takeawayFeeSen,
      taxes: [{ rateBp: l.taxRateBp, baseSen: l.sstBaseSen, taxSen: l.sstSen }],
    }
  })
  const tax = lines.reduce((a, l) => a + l.sstSen, 0)
  if (tax !== totals.sstSen) throw new Error(`The lines' SST adds up to ${tax} sen, the bill charged ${totals.sstSen}`)
  return { lines: out, docChargeSen: totals.serviceChargeSen, roundingSen: totals.roundingSen }
}

/** A bill's mix from its frozen totals. Goods = subtotal − bill discount + packaging; untaxed = goods − SST bases. */
export function billMix(t: BillTotals): Mix {
  const goods = t.subtotalSen - (t.billDiscountSen ?? 0) + t.takeawayFeeSen
  const taxed = t.sstGroups
    .filter((g) => g.baseSen > 0 || g.amountSen > 0)
    .map((g) => ({ rateBp: g.rateBp, baseSen: g.baseSen, taxSen: g.amountSen }))
    .sort((a, b) => a.rateBp - b.rateBp)
  const untaxedSen = goods - taxed.reduce((a, p) => a + p.baseSen, 0)
  if (untaxedSen < 0) throw new Error(`The bill's SST bases are ${-untaxedSen} sen more than its goods`)
  return { taxed, untaxedSen, serviceChargeSen: t.serviceChargeSen, roundingSen: t.roundingSen }
}

export const mixTotal = (m: Mix) =>
  m.taxed.reduce((a, p) => a + p.baseSen + p.taxSen, 0) + m.untaxedSen + m.serviceChargeSen + m.roundingSen

/**
 * What a refund of `refundSen` credits. The whole bill: its mix exactly. Part of it: spread by largest
 * remainder over each SST slice (base + tax), the untaxed goods and the service charge; inside a slice
 * the tax is its proportional part, never more than the slice's tax. No rounding on a partial refund.
 */
export function refundMix(bill: Mix, refundSen: number): Mix {
  const total = mixTotal(bill)
  if (!Number.isInteger(refundSen) || refundSen <= 0 || refundSen > total) {
    throw new Error(`A refund of ${refundSen} sen does not fit a bill of ${total} sen`)
  }
  if (refundSen === total) return { ...bill, taxed: bill.taxed.map((p) => ({ ...p })) }
  const n = bill.taxed.length
  const shares = allocate(refundSen, [...bill.taxed.map((p) => p.baseSen + p.taxSen), bill.untaxedSen, bill.serviceChargeSen])
  const taxed = bill.taxed.map((p, i) => {
    const whole = p.baseSen + p.taxSen
    const taxSen = whole > 0 ? Math.min(p.taxSen, Math.round((shares[i] * p.taxSen) / whole)) : 0
    return { rateBp: p.rateBp, baseSen: shares[i] - taxSen, taxSen }
  })
  return { taxed, untaxedSen: shares[n], serviceChargeSen: shares[n + 1], roundingSen: 0 }
}

export function addMix(a: Mix, b: Mix): Mix {
  const byRate = new Map<number, TaxPart>()
  for (const p of [...a.taxed, ...b.taxed]) {
    const q = byRate.get(p.rateBp) ?? { rateBp: p.rateBp, baseSen: 0, taxSen: 0 }
    byRate.set(p.rateBp, { rateBp: p.rateBp, baseSen: q.baseSen + p.baseSen, taxSen: q.taxSen + p.taxSen })
  }
  return {
    taxed: [...byRate.values()].sort((x, y) => x.rateBp - y.rateBp),
    untaxedSen: a.untaxedSen + b.untaxedSen,
    serviceChargeSen: a.serviceChargeSen + b.serviceChargeSen,
    roundingSen: a.roundingSen + b.roundingSen,
  }
}

/** A mix as lines: one per SST rate, one for untaxed goods, one for the service charge (empty parts left out). */
export function mixLines(mix: Mix, label: string, classification: string): DocLine[] {
  const one = (description: string, sen: number, part: TaxPart): DocLine => ({
    description, classification, qty: 1, unitPriceSen: sen, allowanceSen: 0, chargeSen: 0, taxes: [part],
  })
  const out: DocLine[] = []
  for (const p of mix.taxed) {
    if (p.baseSen > 0 || p.taxSen > 0) out.push(one(`${label}, SST ${pct(p.rateBp)}`, p.baseSen, { ...p }))
  }
  if (mix.untaxedSen > 0) out.push(one(`${label}, no SST`, mix.untaxedSen, { rateBp: 0, baseSen: mix.untaxedSen, taxSen: 0 }))
  if (mix.serviceChargeSen > 0) {
    out.push(one(`${label}, service charge`, mix.serviceChargeSen, { rateBp: 0, baseSen: mix.serviceChargeSen, taxSen: 0 }))
  }
  return out
}

/**
 * General Public bills (or refunds) of a month as lines per business day:
 * "Receipts 261025-001 – 261025-212 (212), SST 6%", "…, no SST", "…, service charge".
 * Per-bill lines would pass LHDN's 300 KB document limit.
 */
export function dayLines(entries: DayEntry[], label = 'Receipts'): { lines: DocLine[]; roundingSen: number } {
  const days = new Map<string, DayEntry[]>()
  for (const e of entries) days.set(e.day, [...(days.get(e.day) ?? []), e])
  const lines: DocLine[] = []
  let roundingSen = 0
  for (const day of [...days.keys()].sort()) {
    const list = days.get(day)!
    const mix = list.map((e) => e.mix).reduce(addMix)
    roundingSen += mix.roundingSen
    const nos = list.map((e) => e.billNo).sort()
    lines.push(...mixLines(mix, `${label} ${nos[0]} – ${nos[nos.length - 1]} (${list.length})`, '004'))
  }
  return { lines, roundingSen }
}

export function buildDocument(input: DocInput): Record<string, unknown> {

  if (b.status !== 'paid') throw new PlanError(`Only a paid bill can be e-invoiced (this one is ${b.status})`, 409)
  if (!b.einvoiceFrom) {
    throw new PlanError('This outlet is not reported by us yet: set "Report e-invoices from" on the E-invoice screen first', 409)
  }
  if (!b.businessDay || b.businessDay < b.einvoiceFrom) {
    throw new PlanError(`This bill is from before ${b.einvoiceFrom}, when this outlet's e-invoices start: Feedme reports it`, 409)
  }
  if (b.totalSen > OVER_LIMIT_SEN && !buyer) throw new PlanError("A bill over RM 10,000 needs the buyer's details", 409)
  return billInvoice(src.lines, src.totals, b.totalSen, ctx, buyer)
}

/** A month's remaining bills as one consolidated invoice to General Public, lines per business day and rate. */
export function planConsolidated(bills: MonthBill[], period: { start: string; end: string }, ctx: PlanCtx): Planned {
  if (bills.length === 0) throw new PlanError('No bills to consolidate')
  const parts = dayLines(bills.map((b) => ({ billNo: b.billNo, day: b.day, mix: mixOf(b.totals, b.billNo) })), 'Receipts')
  return checked({
    kind: 'consolidated_invoice',
    totalSen: bills.reduce((a, b) => a + b.totalSen, 0),
    build: (codeNumber) => ({
      kind: 'consolidated_invoice', codeNumber, issuedAt: ctx.issuedAt, supplier: ctx.supplier, buyer: GENERAL_PUBLIC,
      lines: parts.lines, docChargeSen: 0, roundingSen: parts.roundingSen, period,
    }),
  }, 'the bills are')
}

/** A refund of an individually invoiced bill: a credit note to the same buyer, naming that invoice. */
export function planCreditNote(r: PendingRefund, ctx: PlanCtx): Planned {
  const mix = refundShare(r)
  const lines = mixLines(mix, `Refund of receipt ${r.billNo}`, '022')
  const ref: DocRef = { codeNumber: r.invoiceCode, uuid: r.invoiceUuid }
  return checked({
    kind: 'credit_note',
    totalSen: r.amountSen,
    build: (codeNumber) => ({
      kind: 'credit_note', codeNumber, issuedAt: ctx.issuedAt, supplier: ctx.supplier, buyer: r.invoiceBuyer ?? GENERAL_PUBLIC,
      lines, docChargeSen: 0, roundingSen: mix.roundingSen, references: [ref],
    }),
  }, 'the refund is')
}

/** A month's refunds of consolidated bills: one consolidated credit note naming each consolidated invoice once. */
export function planConsolidatedCreditNote(
  refunds: PendingRefund[], period: { start: string; end: string }, ctx: PlanCtx,
): Planned {
  if (refunds.length === 0) throw new PlanError('No refunds to credit')
  const parts = dayLines(refunds.map((r) => ({ billNo: r.billNo, day: r.refundDay, mix: refundShare(r) })), 'Refunds of receipts')
  const references = [...new Map(refunds.map((r) => [r.invoiceUuid, { codeNumber: r.invoiceCode, uuid: r.invoiceUuid }])).values()]
  return checked({
    kind: 'consolidated_credit_note',
    totalSen: refunds.reduce((a, r) => a + r.amountSen, 0),
    build: (codeNumber) => ({
      kind: 'consolidated_credit_note', codeNumber, issuedAt: ctx.issuedAt, supplier: ctx.supplier, buyer: GENERAL_PUBLIC,
      lines: parts.lines, docChargeSen: 0, roundingSen: parts.roundingSen, period, references,
    }),
  }, 'the refunds are')
}

export const businessDay = (at: Date): string => new Date(at.getTime() + 2 * 3600_000).toISOString().slice(0, 10)

  return m === 1 ? `${y - 1}-12` : `${y}-${String(m - 1).padStart(2, '0')}`
}

export function monthEnd(month: string): string {
  const [y, m] = month.split('-').map(Number)
  return new Date(Date.UTC(y, m, 0)).toISOString().slice(0, 10)
}

/** Days 1–7 of a business month: last month is consolidated (LHDN allows 7 days). */
export const inConsolidationWindow = (day: string) => Number(day.slice(8, 10)) <= 7

/** The pg_cron caller's header against the function secret, in constant time; a short or missing secret never matches. */
export function jobSecretMatches(given: string | null, expected: string | undefined): boolean {
  if (!expected || expected.length < 32 || !given || given.length !== expected.length) return false
  let diff = 0
  for (let i = 0; i < expected.length; i++) diff |= given.charCodeAt(i) ^ expected.charCodeAt(i)
  return diff === 0
}

/** issued: sent (submitted / valid); waiting: a draft to resend; nothing: no work; rejected: LHDN said no;
 *  refused: we did not send (a check failed, or an error). */
export interface StepResult {

  codeNumber?: string
  status?: string
  error?: string

export interface JobSteps {

  setUp(): Promise<{ ok: true } | { ok: false; reason: string }>
  /** Drafts and submitted documents of the current environment. */
  pendingDocuments(): Promise<PendingDoc[]>
  refresh(doc: PendingDoc): Promise<{ status: string }>
  /** Outlets with a start date. */
  outlets(): Promise<{ id: string; einvoiceFrom: string | null }[]>
  failures(key: string): Promise<number>
  record(ref: AttemptRef, ok: boolean, error: string | null): Promise<void>

  creditNote(refund: PendingRefund): Promise<StepResult>

  refundMonths(before: string): Promise<{ branchId: string; month: string }[]>
  consolidatedCreditNote(branchId: string, month: string): Promise<StepResult>

export interface JobReport {
  businessDay: string
  setUp: boolean
  notSetUp?: string
  refreshed: { codeNumber: string; status: string }[]
  consolidated: StepLine[]
  creditNotes: StepLine[]
  errors: string[]
}

export type RunOutcome = 'not_set_up' | 'ok' | 'errors'

export function runOutcome(r: JobReport): RunOutcome {
  if (!r.setUp) return 'not_set_up'
  const bad = (l: StepLine) => l.outcome === 'rejected' || l.outcome === 'refused' || l.outcome === 'stopped'
  return r.errors.length > 0 || r.consolidated.some(bad) || r.creditNotes.some(bad) ? 'errors' : 'ok'
}

export const emptyReport = (day: string): JobReport =>
  ({ businessDay: day, setUp: true, refreshed: [], consolidated: [], creditNotes: [], errors: [] })

const message = (e: unknown) => (e instanceof Error ? e.message : String(e))

/** LHDN turning down a consolidated document counts against its outlet-month. */
export function refOfDocument(d: PendingDoc): AttemptRef | null {
  if (!d.periodStart) return null
  if (d.kind === 'consolidated_invoice') return conRef(d.branchId, monthOf(d.periodStart))
  if (d.kind === 'consolidated_credit_note') return ccnRef(d.branchId, monthOf(d.periodStart))
  return null
}

/** One counted try: skipped at MAX_ATTEMPTS (unless forced); a refusal or rejection adds one; a success resets. */
async function attempt(s: JobSteps, ref: AttemptRef, run: () => Promise<StepResult>, force: boolean): Promise<StepLine> {
  const failures = await s.failures(ref.key)
  if (!force && failures >= MAX_ATTEMPTS) return { key: ref.key, outcome: 'stopped' }
  let r: StepResult
  try {
    r = await run()
  } catch (e) {
    r = { outcome: 'refused', error: message(e) }
  }
  if (r.outcome === 'rejected' || r.outcome === 'refused') await s.record(ref, false, r.error ?? r.outcome)
  else if ((r.outcome === 'issued' || r.outcome === 'nothing') && failures > 0) await s.record(ref, true, null)
  return { key: ref.key, ...r }
}

/** Step 1: every draft is resent and every submitted document asked about. */
export async function runRefresh(s: JobSteps, report: JobReport): Promise<void> {
  let docs: PendingDoc[]
  try {
    docs = await s.pendingDocuments()
  } catch (e) {
    report.errors.push(`Pending documents: ${message(e)}`)
    return
  }
  for (const d of docs) {
    try {
      const after = await s.refresh(d)
      report.refreshed.push({ codeNumber: d.codeNumber, status: after.status })
      const ref = refOfDocument(d)
      if (ref && (after.status === 'invalid' || after.status === 'rejected')) {
        await s.record(ref, false, `LHDN: ${d.codeNumber} is ${after.status}`)
      }
    } catch (e) {
      report.errors.push(`${d.codeNumber}: ${message(e)}`)
    }
  }
}

/** Step 2 (days 1–7): last month for every outlet whose start date is in or before it. */
export async function runConsolidation(s: JobSteps, report: JobReport, day: string): Promise<void> {
  const month = previousMonth(monthOf(day))
  try {
    for (const o of await s.outlets()) {
      if (!o.einvoiceFrom || o.einvoiceFrom > monthEnd(month)) continue
      report.consolidated.push(await attempt(s, conRef(o.id, month), () => s.consolidate(o.id, month), false))
    }
  } catch (e) {
    report.errors.push(`Consolidation: ${message(e)}`)
  }
}

/** Step 3: single credit notes, then one consolidated credit note per outlet and past month with refunds due. */
export async function runCreditNotes(s: JobSteps, report: JobReport, day: string, force = false): Promise<void> {
  try {
    for (const r of await s.singleRefunds()) {
      report.creditNotes.push(await attempt(s, cnRef(r.branchId, r.refundId), () => s.creditNote(r), force))
    }
    for (const m of await s.refundMonths(`${monthOf(day)}-01`)) {
      report.creditNotes.push(await attempt(s, ccnRef(m.branchId, m.month), () => s.consolidatedCreditNote(m.branchId, m.month), force))
    }
  } catch (e) {
    report.errors.push(`Credit notes: ${message(e)}`)
  }
}

/** The daily run. Not set up: nothing is called. A failing step never stops the next. */
export async function runJob(s: JobSteps, now: Date): Promise<JobReport> {
  const day = businessDay(now)
  const report = emptyReport(day)
  const ready = await s.setUp()
  if (!ready.ok) return { ...report, setUp: false, notSetUp: ready.reason }
  await runRefresh(s, report)
  if (inConsolidationWindow(day)) await runConsolidation(s, report, day)
  await runCreditNotes(s, report, day)
  return report
}

// The reconciliation run (spec W5.9): build — never submit — every paid bill's own e-invoice and every outlet-month's
// consolidated invoice, and compare them with the bills and Reports → Overview. Pure; index.ts feeds it
// einvoice_reconcile_source (supabase/migration-2026-11-23-einvoice-w5.sql E6).

import { billInvoice, OVER_LIMIT_SEN, planConsolidated, type PlanCtx } from './documents.ts'
import { monthEnd } from './job.ts'
import { buildDocument, documentTotals, type BillTotals, type LedgerLine, type Party } from './ubl.ts'

/** A stand-in seller: the company details may not be filled in, and nothing is sent. */
export const RECONCILE_SUPPLIER: Party = {
  name: 'Reconciliation only', tin: 'C0000000000', idType: 'BRN', idValue: '000000000000', sstNo: 'NA', ttxNo: 'NA',
  msicCode: '56101', activity: 'Reconciliation', address: { line: 'NA', city: 'NA', stateCode: '17', countryCode: 'MYS' },
  phone: 'NA',
}

export interface ReconcileBill {
  id: string; branchId: string; billNo: string; day: string; totalSen: number; totals: BillTotals | null; lines: LedgerLine[]
}
export interface ReconcileMonthIn { branchId: string; month: string; overviewSen: number }
export interface ReconcileSource { bills: ReconcileBill[]; months: ReconcileMonthIn[] }

export interface MonthCheck {
  branchId: string
  month: string
  bills: number
  billsSen: number
  consolidatedSen: number
  overLimitSen: number
  overviewSen: number | null
  ok: boolean
  problem?: string
}
export interface ReconcileReport {
  bills: number
  singleOk: number
  singleProblems: { branchId: string; billNo: string; problem: string }[]
  months: MonthCheck[]
  ok: boolean
}

const message = (e: unknown) => (e instanceof Error ? e.message : String(e))

export function reconcile(src: ReconcileSource, issuedAt = new Date('2026-01-01T00:00:00Z')): ReconcileReport {
  const ctx: PlanCtx = { supplier: RECONCILE_SUPPLIER, issuedAt }

  const singleProblems: ReconcileReport['singleProblems'] = []
  let singleOk = 0
  for (const b of src.bills) {
    try {
      buildDocument(billInvoice(b.lines, b.totals, b.totalSen, ctx, null).build('RECONCILE'))
      singleOk++
    } catch (e) {
      singleProblems.push({ branchId: b.branchId, billNo: b.billNo, problem: message(e) })
    }
  }

  const groups = new Map<string, ReconcileBill[]>()
  for (const b of src.bills) {
    const k = `${b.branchId}|${b.day.slice(0, 7)}`
    groups.set(k, [...(groups.get(k) ?? []), b])
  }
  const overview = new Map(src.months.map((m) => [`${m.branchId}|${m.month}`, m.overviewSen]))

  const months = [...groups.keys()].sort().map((k): MonthCheck => {
    const list = groups.get(k)!
    const [branchId, month] = k.split('|')
    const billsSen = list.reduce((a, b) => a + b.totalSen, 0)
    const small = list.filter((b) => b.totalSen <= OVER_LIMIT_SEN)
    const overLimitSen = billsSen - small.reduce((a, b) => a + b.totalSen, 0)
    const overviewSen = overview.get(k) ?? null
    let consolidatedSen = 0
    let problem: string | undefined
    try {
      if (small.length > 0) {
        const p = planConsolidated(
          small.map((b) => ({ id: b.id, billNo: b.billNo, day: b.day, totalSen: b.totalSen, totals: b.totals })),
          { start: `${month}-01`, end: monthEnd(month) }, ctx)
        const input = p.build('RECONCILE')
        buildDocument(input)
        consolidatedSen = documentTotals(input).payable
      }
    } catch (e) {
      problem = message(e)
    }
    if (!problem && consolidatedSen + overLimitSen !== billsSen) {
      problem = `Consolidated ${consolidatedSen} sen + over RM 10,000 ${overLimitSen} sen is not the bills' ${billsSen} sen`
    }
    if (!problem && overviewSen !== billsSen) problem = `Reports → Overview says ${overviewSen} sen, the bills ${billsSen} sen`
    return { branchId, month, bills: list.length, billsSen, consolidatedSen, overLimitSen, overviewSen, ok: !problem, ...(problem ? { problem } : {}) }
  })

  return { bills: src.bills.length, singleOk, singleProblems, months, ok: singleProblems.length === 0 && months.every((m) => m.ok) }
}

async function send(admin: SupabaseClient, client: MyInvoisClient, row: Record<string, any>) {
  try {
    const r = await client.submit([{ codeNumber: row.code_number, document: row.payload }])
    const ok = r.accepted.find((a) => a.codeNumber === row.code_number)
    if (ok) {
      return updateDoc(admin, row.id, {
        status: 'submitted', submission_uid: r.submissionUid, lhdn_uuid: ok.uuid,
        submitted_at: new Date().toISOString(), errors: null,
      })
    }
    await releaseLinks(admin, row.id)
    return updateDoc(admin, row.id, { status: 'rejected', submission_uid: r.submissionUid, errors: r.rejected })
  } catch (e) {
    if (e instanceof MyInvoisError && e.status >= 400 && e.status < 500 && e.status !== 401 && e.status !== 429) {
      await releaseLinks(admin, row.id)
      return updateDoc(admin, row.id, { status: 'rejected', errors: { status: e.status, body: e.body } })
    }
    // Credentials, rate limit, network or LHDN down: keep the draft and its bills for a resend.
    return updateDoc(admin, row.id, {
      errors: { message: message(e), ...(e instanceof MyInvoisError ? { status: e.status, body: e.body } : {}) },
    })
  }
}

/** Read LHDN's verdict on a submitted document, or resend a draft that never reached LHDN. */
async function refreshDocument(admin: SupabaseClient, client: MyInvoisClient, row: Record<string, any>) {
  if (row.status === 'draft') return send(admin, client, row)
  if (row.status !== 'submitted') return row
  const summary = (await client.getSubmission(row.submission_uid)).find((d) => d.uuid === row.lhdn_uuid)
  if (!summary || summary.status === 'Submitted') return row
  if (summary.status === 'Valid') {
    return updateDoc(admin, row.id, { status: 'valid', long_id: summary.longId, validated_at: new Date().toISOString(), errors: null })
  }
  await releaseLinks(admin, row.id)
  const errors = summary.status === 'Invalid'
    ? await client.getDocumentDetails(row.lhdn_uuid).catch((e) => ({ message: message(e) }))
    : null
  return updateDoc(admin, row.id, { status: summary.status === 'Invalid' ? 'invalid' : 'cancelled', errors })
}

const withLink = (doc: Record<string, any>) => ({
  ...doc,
  validationUrl: doc.lhdn_uuid && doc.long_id ? validationUrl(doc.environment, doc.lhdn_uuid, doc.long_id) : null,
})

async function recordAttempt(admin: SupabaseClient, ref: AttemptRef, ok: boolean, error: string | null) {

const toPendingRefund = (r: Record<string, any>): PendingRefund => ({

const monthEnded = (month: string) => month < monthOf(businessDay(new Date()))

// ── What each document covers ───────────────────────────────────────────────
/** A past business month's remaining bills of one outlet, from its start date, as one consolidated invoice. */
async function consolidateOutlet(
  admin: SupabaseClient, s: Settings, client: MyInvoisClient, branchId: string, month: string, callerId: string | null,
) {
  if (!monthEnded(month)) throw new Refusal('A month can be consolidated only after its last business day ends (06:00 Malaysia time on the 1st)', 409)
  const { data: outlet, error: outletErr } = await admin.from('branches').select('id, einvoice_from').eq('id', branchId).maybeSingle()
  if (outletErr) throw outletErr
  if (!outlet) throw new Refusal('No such outlet', 404)
  if (!outlet.einvoice_from) throw new Refusal('This outlet is not reported by us yet: set "Report e-invoices from" first', 409)

  const { data: bills, error } = await admin.rpc('einvoice_unlinked_paid_bills', { p_branch_id: branchId, p_month: `${month}-01` })
  if (error) throw error
  if (!bills?.length) return { nothingToDo: true, month }

  const first = `${month}-01`
  const period = { start: outlet.einvoice_from > first ? outlet.einvoice_from : first, end: monthEnd(month) }
  const monthBills: MonthBill[] = bills.map((b: any) => ({ id: b.id, billNo: b.bill_no, day: b.day, totalSen: b.total_sen, totals: b.totals }))
  const planned = plan(() => planConsolidated(monthBills, period, planCtx(s)))
  const doc = await issue(admin, client, {
    branchId, periodStart: period.start, periodEnd: period.end, createdBy: callerId,
  }, { billIds: monthBills.map((b) => b.id), refundIds: [] }, planned)
  return { ...withLink(doc), bills: monthBills.length }
}

/** A refund of an individually invoiced bill. */
async function creditNoteFor(admin: SupabaseClient, s: Settings, client: MyInvoisClient, r: PendingRefund) {
  const planned = plan(() => planCreditNote(r, planCtx(s)))
  const doc = await issue(admin, client, {
    branchId: r.branchId, billId: r.billId, buyer: r.invoiceBuyer, createdBy: null,
  }, { billIds: [], refundIds: [r.refundId] }, planned)
  return withLink(doc)
}

/** An outlet's refunds of one past business month whose bills sit in valid consolidated invoices. */
async function consolidatedCreditNoteFor(admin: SupabaseClient, s: Settings, client: MyInvoisClient, branchId: string, month: string) {
  const { data, error } = await admin.rpc('einvoice_pending_consolidated_refunds', { p_branch_id: branchId, p_month: `${month}-01` })
  if (error) throw error
  const refunds = (data ?? []).map(toPendingRefund)
  if (!refunds.length) return { nothingToDo: true, month }
  const period = { start: `${month}-01`, end: monthEnd(month) }
  const planned = plan(() => planConsolidatedCreditNote(refunds, period, planCtx(s)))
  const doc = await issue(admin, client, {
    branchId, periodStart: period.start, periodEnd: period.end, createdBy: null,
  }, { billIds: [], refundIds: refunds.map((r: PendingRefund) => r.refundId) }, planned)
  return withLink(doc)
}

// ── The daily run's steps ───────────────────────────────────────────────────
/** One step as the runner sees it; a refusal never stops the run. */
async function step(run: () => Promise<Record<string, any>>): Promise<StepResult> {
  try {
    const d = await run()
    if (d.nothingToDo) return { outcome: 'nothing' }
    const base = { codeNumber: d.code_number as string, status: d.status as string }
    if (d.status === 'rejected') return { ...base, outcome: 'rejected', error: JSON.stringify(d.errors ?? null).slice(0, 500) }
    if (d.status === 'draft') return { ...base, outcome: 'waiting', ...(d.errors ? { error: JSON.stringify(d.errors).slice(0, 500) } : {}) }
    return { ...base, outcome: 'issued' }
  } catch (e) {
    return { outcome: 'refused', error: message(e) }
  }
}

function jobSteps(admin: SupabaseClient, s: Settings): JobSteps {
  let client: MyInvoisClient | null = null
  const ready = () => client ?? (client = readyClient(s))
  return {
    async setUp() {
      try {
        ready()
        return { ok: true }
      } catch (e) {
        return { ok: false, reason: message(e) }
      }
    },
    async pendingDocuments(): Promise<PendingDoc[]> {
      const { data, error } = await admin.from('einvoice_documents')
        .select('id, code_number, kind, branch_id, period_start, status')
        .in('status', ['draft', 'submitted']).eq('environment', s.environment).order('created_at')
      if (error) throw error
      return (data ?? []).map((d: any) => ({
        id: d.id, codeNumber: d.code_number, kind: d.kind, branchId: d.branch_id, periodStart: d.period_start, status: d.status,
      }))
    },
    async refresh(doc) {
      const after = await refreshDocument(admin, ready(), await loadDocument(admin, doc.id))
      return { status: after.status }
    },
    async outlets() {
      const { data, error } = await admin.from('branches').select('id, einvoice_from').not('einvoice_from', 'is', null)
      if (error) throw error
      return (data ?? []).map((b: any) => ({ id: b.id, einvoiceFrom: b.einvoice_from }))
    },
    async failures(key) {
      const { data, error } = await admin.from('einvoice_job_attempts').select('failures').eq('key', key).maybeSingle()
      if (error) throw error
      return data?.failures ?? 0
    },
    record: (ref, ok, error) => recordAttempt(admin, ref, ok, error),
    consolidate: (branchId, month) => step(() => consolidateOutlet(admin, s, ready(), branchId, month, null)),
    async singleRefunds() {
      const { data, error } = await admin.rpc('einvoice_pending_single_refunds')
      if (error) throw error
      return (data ?? []).map(toPendingRefund)
    },
    creditNote: (r) => step(() => creditNoteFor(admin, s, ready(), r)),
    async refundMonths(before) {
      const { data, error } = await admin.rpc('einvoice_consolidated_refund_months', { p_before: before })
      if (error) throw error
      return (data ?? []).map((m: any) => ({ branchId: m.branch_id, month: String(m.month).slice(0, 7) }))
    },
    consolidatedCreditNote: (branchId, month) => step(() => consolidatedCreditNoteFor(admin, s, ready(), branchId, month)),
  }
}

// ── Actions ─────────────────────────────────────────────────────────────────
async function actionStatus(s: Settings) {
  const c = credentials()
  let token: string = 'not tried'
  if (c.present.clientId && c.present.clientSecret) {
    try {
      await new MyInvoisClient(s.environment, c.id, c.secret).accessToken()
      token = 'ok'
    } catch (e) {
      token = e instanceof MyInvoisError ? `refused (${e.status})` : `failed: ${message(e)}`
    }
  }
  return {
    environment: s.environment,
    credentials: c.present,
    settingsMissing: missingSettings(s),
    signing: s.environment === 'production' ? 'required, not built' : 'not needed in sandbox (v1.0)',
    token,
  }
}

async function actionSubmitBill(admin: SupabaseClient, s: Settings, callerId: string | null, body: any) {
  if (typeof body.billId !== 'string') throw new Refusal('billId is required')
  const buyer = buyerParty(body.buyer)
  const client = readyClient(s)
  const { data: src, error } = await admin.rpc('einvoice_bill_source', { p_bill_id: body.billId })
  if (error) throw error
  if (!src) throw new Refusal('No such bill', 404)
  const source = src as BillSource
  const planned = plan(() => planInvoice(source, planCtx(s), buyer))
  const doc = await issue(admin, client, {
    branchId: source.bill.branchId, billId: source.bill.id, buyer, createdBy: callerId,
  }, { billIds: [source.bill.id], refundIds: [] }, planned)
  return withLink(doc)
}

async function actionConsolidate(admin: SupabaseClient, s: Settings, callerId: string | null, body: any) {
  if (typeof body.branchId !== 'string') throw new Refusal('branchId is required')
  if (typeof body.month !== 'string' || !/^\d{4}-(0[1-9]|1[0-2])$/.test(body.month)) throw new Refusal('month must be YYYY-MM')
  if (!monthEnded(body.month)) throw new Refusal('A month can be consolidated only after its last business day ends (06:00 Malaysia time on the 1st)', 409)
  const client = readyClient(s)
  const ref = conRef(body.branchId, body.month)
  try {
    const r: Record<string, any> = await consolidateOutlet(admin, s, client, body.branchId, body.month, callerId)
    const rejected = r.status === 'rejected'
    await recordAttempt(admin, ref, !rejected, rejected ? 'LHDN rejected the document' : null)
    return r
  } catch (e) {
    if (e instanceof Refusal) await recordAttempt(admin, ref, false, e.message).catch((err) => console.error(err))
    throw e
  }
}

async function actionRefresh(admin: SupabaseClient, s: Settings, body: any) {
  if (typeof body.documentId !== 'string') throw new Refusal('documentId is required')
  const row = await loadDocument(admin, body.documentId)
  if (row.environment !== s.environment) throw new Refusal(`This document was sent to ${row.environment}; settings now say ${s.environment}`, 409)
  return withLink(await refreshDocument(admin, readyClient(s), row))
}

/** The screen's Retry for credit notes: everything due now, stopped ones included. */
async function actionCreditNotes(admin: SupabaseClient, s: Settings): Promise<JobReport> {
  readyClient(s)
  const report = emptyReport(businessDay(new Date()))
  await runCreditNotes(jobSteps(admin, s), report, report.businessDay, true)
  return report
}

async function actionRun(admin: SupabaseClient, s: Settings) {
  const startedAt = new Date()
  let report: JobReport
  try {
    report = await runJob(jobSteps(admin, s), startedAt)
  } catch (e) {
    report = { ...emptyReport(businessDay(startedAt)), errors: [`Run: ${message(e)}`] }
  }
  const outcome = runOutcome(report)
  const { error } = await admin.from('einvoice_job_runs').insert({
    started_at: startedAt.toISOString(), finished_at: new Date().toISOString(), environment: s.environment, outcome, report,
  })
  if (error) throw error
  return { outcome, report }
}

async function actionReconcile(admin: SupabaseClient, body: any) {
  const day = (v: unknown, fallback: string) => (typeof v === 'string' && /^\d{4}-\d{2}-\d{2}$/.test(v) ? v : fallback)
  const { data, error } = await admin.rpc('einvoice_reconcile_source', {
    p_from: day(body.from, '2000-01-01'), p_to: day(body.to, businessDay(new Date())),
  })
  if (error) throw error
  return reconcile(data as ReconcileSource)
}

export function runSummary(r: JobRun): string {
  if (r.outcome === 'not_set_up') return `Not set up — nothing sent${r.report.notSetUp ? ` (${r.report.notSetUp})` : ''}`
  const rep = r.report
  const sent = (l?: JobStepJson[]) => (l ?? []).filter((x) => x.outcome === 'issued').length
  const problems = (rep.errors?.length ?? 0)
    + [...(rep.consolidated ?? []), ...(rep.creditNotes ?? [])].filter((x) => ['rejected', 'refused', 'stopped'].includes(x.outcome)).length
  return [
    `${rep.refreshed?.length ?? 0} checked with LHDN`,
    `${sent(rep.consolidated)} monthly sent`,
    `${plural(sent(rep.creditNotes), 'credit note')} sent`,
    ...(problems ? [plural(problems, 'problem')] : []),

}

export function bannerMessages(i: BannerInput): string[] {
  const out: string[] = []
  const rejected = openProblems(i.docs).length
  if (rejected) out.push(`LHDN did not accept ${rejected === 1 ? 'an e-invoice' : `${rejected} e-invoices`}.`)
  const stopped = i.stopped.filter((a) => a.failures >= STOP_AT).length

    out.push(`${large === 1 ? 'A bill' : `${large} bills`} over RM 10,000 ${large === 1 ? 'needs' : 'need'} the buyer's details for an individual e-invoice.`)
  }
  if (i.lastRun?.outcome === 'not_set_up' && i.lastRun.environment === 'production') {
    out.push('E-invoicing is not set up: nothing is being sent to LHDN.')
  }
  return out
}

import { useEffect, useState } from 'react'
import { hasLiveDocument, startDateProblem, type EinvoiceDoc } from './einvoice'
import { fetchOutlets, setOutletStart, type OutletRow } from './einvoiceApi'

/** Per outlet: the first business day this POS reports e-invoices for (spec W5.3). Empty = Feedme still does. */
export function EinvoiceOutlets({ docs }: { docs: EinvoiceDoc[] }) {
  const [outlets, setOutlets] = useState<OutletRow[]>([])
  const [draft, setDraft] = useState<Record<string, string>>({})
  const [errors, setErrors] = useState<Record<string, string>>({})
  const [saved, setSaved] = useState<string | null>(null)
  const [loadError, setLoadError] = useState<string | null>(null)

  const load = async () => {
    try {
      const rows = await fetchOutlets()
      setOutlets(rows)
      setDraft(Object.fromEntries(rows.map((o) => [o.id, o.einvoice_from ?? ''])))
    } catch (e) {
      setLoadError(e instanceof Error ? e.message : String(e))
    }
  }
  useEffect(() => { void load() }, [])

  const save = async (o: OutletRow) => {
    const next = draft[o.id] ?? ''
    setSaved(null)
    const problem = startDateProblem(next, o.einvoice_from, hasLiveDocument(docs, o.id))
    if (problem) { setErrors({ ...errors, [o.id]: problem }); return }
    try {
      await setOutletStart(o.id, next || null)
      setErrors({ ...errors, [o.id]: '' })
      setSaved(o.id)
      await load()
    } catch (e) {
      setErrors({ ...errors, [o.id]: e instanceof Error ? e.message : String(e) })
    }
  }

  return (
    <section className="rounded-xl border border-border bg-card p-4">
      <h2 className="font-semibold">Report e-invoices from</h2>
