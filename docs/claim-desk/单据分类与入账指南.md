# 单据分类与入账指南

**公司：** CRAFTALE SDN. BHD.
**会计软件：** AutoCount Cloud Accounting
**用途：** 统一淘宝、Shopee、纸本单据的分类方式，方便每年 Audit 和报税
**版本：** 2026-10-29

> 本指南用马来西亚会计 / 审计的通用名词。涉及税务的规定（Self-billed e-Invoice 期限、e-Invoice 实施阶段、扣税资格）请以 LHDN 最新指引和 tax agent 意见为准。

---

## 1. 核心概念

| 名词 | 意思 |
|---|---|
| **Source Document**（原始凭证） | 证明交易发生的单据：发票、收据、e-Invoice、订单截图、付款证明 |
| **Supporting Document**（佐证文件） | 辅助原始凭证的文件，例如付款截图、英文翻译、Delivery Order |
| **Voucher** | AutoCount 里的一笔记录，例如 Purchase Invoice、Payment Voucher |
| **Audit Trail** | 每张 Source Document 都能对上一张 Voucher，每张 Voucher 都能找回原始单据 |
| **Creditor** | 供应商（Accounts Payable 的对象） |
| **e-Invoice / MyInvois** | LHDN 的电子发票系统。有效的 e-Invoice 会有 **UUID** 和 QR code |
| **Self-billed e-Invoice** | 供应商不能开马来西亚 e-Invoice 时（例如外国卖家），由买方（公司）自己在 MyInvois 开 |

---

## 2. 三类单据的分类

| 来源 | 审计上的单据名称 | 交易类型 | AutoCount 入账 | e-Invoice 处理 |
|---|---|---|---|---|
| **纸本发票**（本地供应商） | Supplier Invoice；有 SST 的叫 Tax Invoice；小额的是 Cash Bill / Receipt | Local Purchase（赊账或现付） | 赊账：**Purchase Invoice**（挂在 Creditor 下）<br>已付：**Cash Book → Payment Voucher (PV)** | 应由供应商开 e-Invoice；纸本作为 Supporting Document |
| **淘宝订单**（员工先付） | **Foreign Supplier Purchase**（Importation of Goods / Low Value Goods），以 **Staff Expense Claim** 报销 | 外币采购（CNY），员工垫付 | **Expense Claim → Payment Voucher** 付给员工 | 外国卖家不开马来西亚 e-Invoice → 公司开 **Self-billed e-Invoice** |
| **Shopee 订单** | **Validated e-Invoice**（有 UUID 和 QR） | Local e-Commerce Purchase | Purchase Invoice 或 Cash Purchase | 下单后在订单页按 **Request e-Invoice**，填公司 TIN |

### 淘宝单的佐证文件（缺一不可）

1. **Order Confirmation**：淘宝订单详情截图（中文原件）
2. **English Translation**：英文翻译（记录必须是英文或马来文）
3. **Proof of Payment**：Alipay 或信用卡付款记录
4. **Staff Expense Claim Form**：员工签名、主管批准、会计核对

### 淘宝单要拆开记的项目

| 项目 | 记到哪里 |
|---|---|
| 货品本身 | 按用途选科目（见第 3 节） |
| 运费 / 集运费 | Freight Inwards / Carriage Inwards |
| 10% LVG Sales Tax | 算进成本，不能拿回 |
| 汇率 | 记 CNY 原价、付款当天汇率（BNM）和换算后的 MYR |

### Shopee 单的注意事项

- 每一单都要按 **Request e-Invoice**，不按的话，卖家只会开 consolidated e-Invoice，公司拿不到自己名下的那一张。
- 卖家开好后，LHDN 会发通知到公司 Gmail，发件人是 `noreply@myinvois.hasil.gov.my`，标题是 "Notifikasi Penerimaan Dokumen e-Invois"。
- 通知里有供应商名称、UUID、e-Invoice 号码和日期，**没有金额**。金额要去 MyInvois 看，或下载 e-Invoice PDF。

## 3. 每张单要标的 4 个分类维度

### 3.1 Document Type（单据类型）

- Supplier Invoice
- Tax Invoice (SST)
- Cash Bill / Receipt
- Validated e-Invoice
- Foreign Purchase – Staff Expense Claim
- Credit Note
- Other Supporting Document

### 3.2 Account（会计科目）

| 大类 | 例子 |
|---|---|
| **Purchases / Cost of Sales** | 买来转卖或做产品用的货 |
| **Operating Expenses** | Freight Inwards、Packaging Materials、Office Supplies & Stationery、Repair & Maintenance、Upkeep of Premises、Transport & Delivery、Advertising & Promotion、Software & Subscriptions、Telephone & Internet、Staff Welfare、Entertainment、Sundry Expenses |
| **Fixed Asset (PPE)** | 设备、机器、电脑等资本性开支（Capital Expenditure） |

> 科目代码请按公司在 AutoCount 里的 Chart of Accounts 填写。

### 3.3 Tax Treatment（税务处理）

| 分类 | 说明 |
|---|---|
| **Allowable expense**（ITA 1967 s33） | 为了赚取收入而产生的开支，可以扣税 |
| **Capital allowance**（Schedule 3） | 资产不能直接扣，按 capital allowance 扣。单件 RM2,000 以内可当 **Small Value Asset** 一次扣完 |
| **Partly allowable** | 例如部分 entertainment 只能扣 50% |
| **Non-allowable / private** | 私人开支、罚款等，不能扣税 |
| **To be decided by tax agent** | 不确定的先这样标，交给 tax agent 判断 |

### 3.4 Payment（付款状态）

| 状态 | AutoCount |
|---|---|
| **Unpaid**（Accounts Payable） | Purchase Invoice，之后用 Payment 冲账 |
| **Paid by company** | Payment Voucher / Cash Purchase |
| **Staff-paid**（Reimbursement） | Expense Claim → Payment Voucher 付给员工 |

## 4. 审计 Checklist（Audit Assertions）

| 审计要求 | 每张单要有什么 |
|---|---|
| **Occurrence**（交易真的发生了） | 原始单据 + 付款证明 |
| **Completeness**（没有漏记） | 每月把 MyInvois 收到的 e-Invoice 和账簿对一遍 |
| **Accuracy**（金额正确） | 金额、币别、汇率、SST |
| **Cut-off**（入对会计期） | 用单据日期决定会计期 |
| **Classification**（科目正确） | Account 和 Tax Treatment 选对 |
| **语言** | 记录用英文或马来文；中文单必须附英文翻译 |
| **Authorisation**（有批准） | Expense Claim 要有报销人、批准人、会计三方签名 |
| **Retention**（保存期限） | 保存 **7 年**（ITA 1967 s82） |

### Audit Trail 命名规则

文件名用 Voucher No. 开头，方便对照：

```
<Voucher No>_<来源>_<供应商单号>.pdf
例：EC-2610-001_TAOBAO_2849xxxxxxxx.pdf
    PI-2610-012_SHOPEE_INV-0001.pdf
```

### Voucher No. 前缀

| 前缀 | 用于 |
|---|---|
| **PI** | Purchase Invoice（赊账） |
| **PV** | Payment Voucher（公司已付） |
| **EC** | Expense Claim（员工报销） |
| **CN** | Credit Note |

格式：`前缀-YYMM-流水号`，例如 `EC-2610-001`。

## 5. 处理流程

```
收集 → 识别 → 翻译 / 分类 → 会计审核 → 入 AutoCount → 归档
```

| 状态 | 意思 | 谁处理 |
|---|---|---|
| **Needs info**（待补资料） | 缺金额、供应商或单据 | 经手人 / 会计 |
| **Draft**（待审核） | 资料齐了，等会计看 | 会计 |
| **Reviewed**（已审核） | 会计确认了分类和金额 | 会计 |
| **Posted to AutoCount**（已入账） | 已经导入或输入 AutoCount | 会计 |
| **Cancelled**（已取消） | 供应商在 MyInvois 取消了，或单据作废 | — |

### 每月例行工作

1. 从 Gmail 同步本月的 MyInvois e-Invoice 通知
2. 补齐 e-Invoice 的金额
3. 收齐纸本单据，扫描存档
4. 处理员工的淘宝报销，并标记要开的 Self-billed e-Invoice
5. 会计核对科目和税务处理，改成 Reviewed
6. 导出 CSV 进 AutoCount，改成 Posted
7. 在 MyInvois 开当月需要的 Self-billed e-Invoice，把 UUID 记回账簿
