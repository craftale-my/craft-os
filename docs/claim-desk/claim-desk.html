每张单都是一份 Source Document（原始凭证），要能对上 AutoCount 里的一张 Voucher，这就是 Audit Trail。

每张单的 4 个分类

  1. Document Type：Supplier Invoice / Receipt / e-Invoice / Expense Claim / Credit Note
  2. Account：Purchases（Cost of Sales）/ Operating Expenses / Fixed Asset（PPE）
  3. Tax Treatment：Allowable（s33 ITA 1967）/ Capital Allowance（单件 ≤ RM2,000 为 Small Value Asset）/ Non-allowable
  4. Payment：Unpaid（Accounts Payable）/ Paid by company / Staff-paid（Reimbursement）

审计 checklist

  1. Occurrence：原始单据 + 付款证明
  2. Accuracy：金额、币别、汇率
  3. Cut-off：日期入对会计期
  4. Classification：科目正确
  5. 语言：英文或马来文（淘宝要附英文翻译）
  6. 保存 7 年（ITA 1967 s82）

Self-billed e-Invoice 的开立期限和公司适用的 e-Invoice 阶段，请和 tax agent 确认。
